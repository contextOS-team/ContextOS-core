## Cross-Phase Integration Report

### Verified E2E Flows (6 complete)

1. **User Authentication** — Login → Supabase → middleware → JWT → dashboard
2. **Integration Status** — Frontend → `/api/integrations/status` → all 5 providers
3. **Embedding Pipeline** — All 9 source types → embedding service → pgvector (Linear, Slack, Fathom, GitHub, Notion, code chunks, comments, reviews, segments)
4. **Webhook Reception** — 3 endpoints (Linear, GitHub, Notion) with HMAC-SHA256 + idempotency
5. **Code Intelligence** — Push webhook → code index worker → tree-sitter → embedding → linking → synthesis template
6. **Context Generation Pipeline** — Infrastructure wired: synthesis → linking → hybrid search → LLM → ContextPage (pending Phase 4 triggers)

### Broken/Partial Flows (5 issues)

| # | Flow | Breaks At | Requirements |
|---|------|-----------|-------------|
| 1 | Linear/Slack OAuth callback | `/dashboard?provider=connected` query params silently ignored — no user feedback | LIN-01, SLCK-01, DASH-04 |
| 2 | Notion OAuth callback | Redirects to `/dashboard?notion=connected` but handler is on `/dashboard/integrations` | DASH-04 |
| 3 | MCP server authentication | Sends API key as Bearer but backend expects Supabase JWT — all calls 401 | MCP-01, MCP-02, MCP-03 |
| 4 | Context page staleness | `mark_context_stale()` defined but never called from webhooks | CTXG-01..06 |
| 5 | Manual sync triggers | `POST /api/linear/sync` and `/api/github/sync` exist but no frontend UI | LIN-02, GH-02 |

### Integration Warnings

- **Slack/Fathom embedding bypass Redis Streams** — These two services call `queue_embedding_generation()` directly instead of `enqueue_embedding_job()`, inconsistent with Linear, GitHub, Notion, and code chunks. Functional but adds latency to event handlers.
- **notion-pages.tsx orphaned** — Component exists but was removed from the UI in Phase 09. Dead code.
- **LLMClient.generate_context_page() dead code** — Method exists but synthesis.py calls `LLMClient.generate()` directly.
