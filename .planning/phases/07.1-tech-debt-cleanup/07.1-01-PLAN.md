**2. Fix RuntimeWarning unawaited coroutines in test files:**

The issue: `session.add()` is a synchronous SQLAlchemy method, but `AsyncMock()` makes ALL attribute accesses return async coroutines. When production code calls `session.add(obj)`, the returned coroutine is never awaited, producing a RuntimeWarning.

Fix: In each test that creates `mock_session = AsyncMock()` and triggers `session.add()` calls, add after the mock creation:
```python
mock_session.add = MagicMock()  # session.add() is synchronous
```

Import `MagicMock` if not already imported.
