Create `backend/src/services/slack_huddles.py` following the Fathom pattern (see `backend/src/services/fathom.py` poll_transcripts):

```python
async def poll_huddle_transcripts(session: AsyncSession, workspace_id: UUID) -> dict:
```

Implementation details:
1. Get bot token via `get_bot_token(session, workspace_id)` from slack_oauth
2. Get monitored channels from `get_cached_channels(session, workspace_id)` -- extract channel IDs from the cached channel selection in workspace_integrations.config. Use the same approach as slack_channels.py: query WorkspaceIntegration for Provider.SLACK, read config["selected_channel_ids"]
3. For each channel, call `_find_huddle_messages(bot_token, channel_id, oldest)` where `oldest` comes from workspace integration config `last_huddle_poll_at`
4. `_find_huddle_messages`: paginate `conversations.history`, filter messages where `msg.get("room", {}).get("call_family") == "huddle"` and `room.get("has_ended")` is truthy
5. For each huddle message, dedup check: query MeetingTranscript where `workspace_id == workspace_id AND source == "slack_huddle" AND raw_data["huddle_room_id"].as_string() == room_id`
6. Get canvas content: `_get_huddle_canvas_content(bot_token, channel_id, room["canvas_thread_ts"])`:
   - Call `conversations.replies(channel=channel_id, ts=canvas_thread_ts)`
   - Find messages with files where `filetype == "canvas"` or `mimetype` starts with `"application/vnd.slack"`
   - For matching file, call `files.info(file=file_id)` to get `url_private`
   - Download content from `url_private` with Authorization header
   - Return content as string, or None if no canvas found
7. Resolve participants: `_resolve_user_names(bot_token, user_ids)` -- call `users.info` for each user ID, return list of display names. Cache within the poll call.
8. Create MeetingTranscript:
   - `source="slack_huddle"`
   - `title=f"Huddle in #{channel_name}"` (get channel name from cached channels)
   - `transcript=canvas_content or "No AI notes available for this huddle."`
   - `summary=None` (let synthesis extract summary)
   - `participants=resolved_names`
   - `meeting_date=datetime.fromtimestamp(room["date_start"], tz=timezone.utc)`
   - `duration_minutes=int((room["date_end"] - room["date_start"]) / 60)`
   - `raw_data={"huddle_room_id": room["id"], "channel_id": channel_id, "canvas_thread_ts": room.get("canvas_thread_ts"), **room}`
9. Queue embedding: `await embedding.queue_embedding_generation(session, workspace_id, "meeting_transcript", [meeting.id])` -- only if canvas_content is present (skip embedding for no-content huddles)
10. Update `last_huddle_poll_at` in workspace integration config (same pattern as Fathom's `last_poll_at`)
11. Handle Slack API errors gracefully: if 403/missing_scope, log warning about re-authorization needed, continue to next channel. If 429 rate limit, respect Retry-After header.
