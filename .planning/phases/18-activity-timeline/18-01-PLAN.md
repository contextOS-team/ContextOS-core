Content:
```sql
-- ============================================================
-- Enable Realtime for Activity Events
-- Phase 18: Activity Timeline
-- ============================================================
-- Without this, postgres_changes subscriptions on activity_events
-- will silently receive no events. The table must be added to the
-- supabase_realtime publication for Realtime to capture changes.
-- ============================================================

ALTER PUBLICATION supabase_realtime ADD TABLE public.activity_events;
```

This is a single ALTER PUBLICATION statement. No conditional logic needed -- the publication is created by Supabase automatically. If the table is already in the publication, PostgreSQL will raise an error, but this migration only runs once.

**types.ts** -- Create the ActivityEvent interface matching the database schema, EventType union, and EVENT_ICONS map:

```typescript
import {
  RefreshCw, CheckCircle2, Sparkles, Plug, Unplug, UserPlus,
  type LucideIcon,
} from 'lucide-react'

export type EventType =
  | 'sync_started'
  | 'sync_completed'
  | 'context_generated'
  | 'integration_connected'
  | 'integration_disconnected'
  | 'user_signed_up'

export interface ActivityEvent {
  id: string
  workspace_id: string
  actor_id: string | null
  event_type: EventType
  metadata: Record<string, unknown>
  created_at: string
}

export const EVENT_ICONS: Record<EventType, LucideIcon> = {
  sync_started: RefreshCw,
  sync_completed: CheckCircle2,
  context_generated: Sparkles,
  integration_connected: Plug,
  integration_disconnected: Unplug,
  user_signed_up: UserPlus,
}
```

**formatters.ts** -- All pure formatting functions. Each uses defensive metadata access with fallbacks:

- `formatEventDescription(event: ActivityEvent): string` -- impersonal descriptions per CONTEXT.md templates. Uses `meta.integration ?? 'Unknown'` for safety.
- `getMetadataChip(event: ActivityEvent): string | null` -- returns chip text or null. sync_completed prioritizes items_count over duration_ms. context_generated shows token count (k format for 1000+).
- `formatTimelineTimestamp(isoDate: string): string` -- "just now" / "{n}m ago" / "{n}h ago" / absolute "3:42 PM" (24h+). Uses `toLocaleTimeString('en-US', { hour: 'numeric', minute: '2-digit', hour12: true })`.
- `formatFullTimestamp(isoDate: string): string` -- hover tooltip format: "Feb 28, 2026 at 3:42 PM".
- `formatDayLabel(dateStr: string): string` -- TODAY / YESTERDAY / weekday uppercase (7 days) / "FEB 24, 2026" (older). Uses midnight-aligned date comparison.
- `groupEventsByDay(events: ActivityEvent[]): Array<{ label: string; date: string; events: ActivityEvent[] }>` -- groups chronologically sorted events into day buckets. Each bucket has the label from formatDayLabel, a date key (YYYY-MM-DD), and the events for that day.

Do NOT import from `@/lib/utils.ts` -- these are timeline-specific formatters co-located with the feature. The existing `formatRelativeTime` has different rules (it shows "d ago" instead of absolute time after 24h).
