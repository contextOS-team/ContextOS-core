**page.tsx** -- Replace the existing static skeleton placeholder entirely. Make it a server component that:

1. Creates server Supabase client via `createClient()` from `@/lib/supabase/server`
2. Gets current user via `supabase.auth.getUser()`
3. Queries `workspace_members` for the user's `workspace_id` (`.select('workspace_id').eq('user_id', user.id).single()`)
4. Fetches initial 30 events from `activity_events` ordered by `created_at DESC`, limited to 30, filtered by workspace_id
5. Renders `<ActivityTimeline initialEvents={events ?? []} workspaceId={workspaceId} />`
6. If no user or no membership, the dashboard layout already redirects, so no additional guard needed

**activity-timeline.tsx** -- `'use client'` component. This is the main piece. Props: `initialEvents: ActivityEvent[]`, `workspaceId: string`.

**State management:**
- `events`: ActivityEvent[] -- all loaded events (initial + paginated). Managed with useState, initialized from props.
- `bufferedEvents`: ActivityEvent[] -- events received via Realtime while user is scrolled down. Not shown until user clicks banner or scrolls to top.
- `hasMore`: boolean -- whether more pages exist (initial: `initialEvents.length === 30`)
- `isLoadingMore`: boolean -- pagination loading state
- `tick`: number -- incremented every 60s to force timestamp re-renders

**Realtime subscription (useEffect):**
- Create channel via `createClient()` from `@/lib/supabase/client`
- Subscribe to `postgres_changes` INSERT on `activity_events` filtered by `workspace_id=eq.${workspaceId}`
- On new event: check scroll position of the nearest scrollable ancestor (use `document.querySelector('main')` or a ref). If scrollTop === 0, prepend event to `events` state with functional update `setEvents(prev => [newEvent, ...prev])`. If scrollTop > 0, add to `bufferedEvents`.
- Cleanup: `supabase.removeChannel(channel)` in useEffect return. This handles React Strict Mode double-invoke correctly.
- Use `useRef` for the callback's scroll position check to avoid stale closure -- store the scroll check function in a ref updated on each render.

**Scroll-aware banner:**
- When `bufferedEvents.length > 0`, show a sticky pill banner at top of timeline: `"N new events"` (up arrow + count)
- Banner style: `bg-muted/80 backdrop-blur-sm text-sm text-foreground rounded-full px-3 py-1.5`
- Banner entry: CSS animation `translateY(-8px)` to `translateY(0)`, 200ms ease-out
- On click: smooth-scroll `main` to top, then merge buffered events into events state, clear buffer
- Also detect when user scrolls back to top manually (scroll event listener on `main`): if scrollTop === 0 and buffer has items, flush buffer into events

**Entry animation for new events:**
- New events (from Realtime, just prepended) get a CSS class that animates: `translateY(-8px) opacity-0` to `translateY(0) opacity-1`, 350ms with `cubic-bezier(0.34, 1.56, 0.64, 1)`.
- Track which event IDs are "new" (received via Realtime in this session) using a `Set<string>` ref. After animation completes (350ms), remove from the set.
- No stagger -- all simultaneous events animate together.

**Timestamp refresh:**
- Single `setInterval` every 60_000ms at the component level that increments `tick` state, causing re-render of all timestamps.
- Clear interval in useEffect cleanup.

**Day-grouped rendering:**
- Call `groupEventsByDay(events)` to get day buckets
- For each day group:
  - Render a sentinel div (0px height, used for IntersectionObserver sticky detection)
  - Render sticky day header: `<div className="section-label sticky top-0 z-10 bg-background pt-6 pb-3 transition-[border] duration-150">` with the day label
  - The sentinel and header: use IntersectionObserver to toggle `border-b border-border` on the header when the sentinel is not intersecting (header is stuck)
  - Render event rows within the group

**Event row rendering (per CONTEXT.md locked decisions):**
- Height: 40px (`h-10`), 8px vertical gap (`gap-2` or `space-y-2`)
- Layout: flex row, items-center
- Left: Icon from `EVENT_ICONS[event.event_type]` at 16px (`w-4 h-4`), `text-muted-foreground`
- Middle: description from `formatEventDescription(event)` in `text-sm text-foreground`. If chip exists (from `getMetadataChip`), append middle dot separator `·` then chip in `text-xs bg-muted rounded px-1.5 py-0.5 font-mono` (JetBrains Mono for data identifiers)
- Right: timestamp from `formatTimelineTimestamp(event.created_at)` in `font-mono text-xs text-muted-foreground ml-auto whitespace-nowrap`, with `title={formatFullTimestamp(event.created_at)}` for hover tooltip
- Hover state (Claude's discretion): subtle `hover:bg-muted/50` with `rounded-md transition-colors duration-150`

**Cursor-based pagination:**
- Sentinel div near bottom of list, observed by IntersectionObserver with `rootMargin: '200px'`
- When intersecting and `hasMore && !isLoadingMore`: fetch next 30 events using `created_at` of oldest event as cursor (`lt` filter on created_at, still ordered DESC, limit 30)
- Fetch via browser Supabase client (same instance as Realtime)
- While loading: show 2 shimmer skeleton rows at bottom (reuse Skeleton component from `@/components/ui/skeleton`)
- If fewer than 30 returned, set `hasMore = false`
- After last event (when `!hasMore`): show end-of-list terminator: centered `"-- Showing last 30 days --"` in `text-xs text-muted-foreground py-4`

**Loading state (initial):**
- If `initialEvents` is empty AND we haven't determined it's truly empty (first render), show skeleton matching the Phase 15 placeholder pattern: 1 day header skeleton + 4 row skeletons, 1 day header skeleton + 2 row skeletons
- Actually, since the server component fetches initial data, the client component always receives events (or empty array). Use empty array length to determine empty vs populated state.

**Empty state (zero events):**
- Centered layout
- Clock icon from Lucide at 32px, `text-muted-foreground`
- Heading: "Activity" in `text-lg font-medium text-foreground`
- Subtext: "Events will appear here as you connect integrations and sync your data." in `text-sm text-muted-foreground max-w-[320px] mx-auto`
- CTA: `<Link href="/dashboard/integrations">` with text "Connect an integration" in `text-sm text-muted-foreground underline-offset-4 hover:underline`
- No teal on the link -- just navigational nudge per CONTEXT.md

**IntersectionObserver for sticky headers:**
- Single useEffect that sets up observers for all `.day-sentinel` elements within the timeline container
- When sentinel is not intersecting, add `border-b border-border` class to the adjacent header element
- When sentinel is intersecting, remove the border class
- Re-run observer setup when events change (use events.length as dependency key)
- Disconnect previous observer in cleanup

**Important implementation notes:**
- Do NOT use `@tanstack/react-query` -- explicitly out of scope per REQUIREMENTS.md
- Do NOT use Framer Motion -- CSS-only animations per Phase 15 decision
- Do NOT auto-scroll user -- respect scroll position per CONTEXT.md locked decision
- Use functional state updates (`setEvents(prev => ...)`) to avoid stale closure in Realtime callback
- The spring curve `cubic-bezier(0.34, 1.56, 0.64, 1)` is the project standard from Phase 15
