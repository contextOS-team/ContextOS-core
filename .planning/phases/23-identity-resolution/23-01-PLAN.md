       - `create_canonical_person(session, workspace_id, canonical_id: UUID, name: str) -> UUID` -- creates a canonical Person node using graph_ops.upsert_node with entity_type="Person", external_id=f"canonical:{canonical_id}", properties={"canonical": True, "canonical_person_id": str(canonical_id)}
       - `lookup_mapping(session, workspace_id, platform, platform_user_id) -> IdentityMapping | None` -- query identity_mappings by workspace+platform+platform_user_id where deleted_at IS NULL
       - `resolve_by_email(session, workspace_id) -> int` -- groups all non-deleted identity_mappings by (workspace_id, email) where email IS NOT NULL. For each unique email: if no canonical_person_id yet, generate a new UUID, create canonical Person node, update all mappings with that email to point to the new canonical_person_id. For each mapping with a canonical_person_id, find its platform Person node (by entity_type="Person" and fingerprint of platform external_id) and create a same_as edge from platform node to canonical node. Returns count of canonical persons created.
       - `resolve_identity_inline(session, workspace_id, entity: ExtractedEntity, entity_node_id: UUID) -> None` -- only acts on Person entities. Extracts platform and platform_user_id from entity properties or external_id. Calls lookup_mapping. If mapping has canonical_person_id, creates same_as edge from entity_node_id to mapping.canonical_person_id (the graph_nodes FK). Non-blocking: logs and returns on any error.
