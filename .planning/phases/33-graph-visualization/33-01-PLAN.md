```python
class GraphNodeResponse(PydanticBaseModel):
    id: str
    entity_type: str          # "Ticket", "Person", "Decision", "PR", "Message", "Code", "NotionPage", "Meeting"
    name: str
    depth: int
    properties: dict

class GraphEdgeResponse(PydanticBaseModel):
    source: str               # node ID
    target: str               # node ID
    relationship_type: str    # "authored", "mentions", "references", "blocks", "depends_on", "related_to", etc.
    properties: dict

class GraphNeighborhoodResponse(PydanticBaseModel):
    ticket_identifier: str
    depth: int
    node_count: int
    edge_count: int
    truncated: bool
    total_available: int | None
    nodes: list[GraphNodeResponse]
    edges: list[GraphEdgeResponse]
```

    **ELK Layout Engine** (`elk-layout.ts`):
    - Export `computeElkLayout(nodes: Node[], edges: Edge[]): Promise<Node[]>` function
    - Convert React Flow nodes/edges to ELK graph format: `{ id, children: [...], edges: [...] }`
    - Use ELK `elk.layered` algorithm with options: `{ 'elk.algorithm': 'org.eclipse.elk.force', 'elk.force.temperature': '0.001', 'elk.spacing.nodeNode': '80' }`
    - After `elk.layout()`, map computed x/y positions back to React Flow nodes
    - Import ELK via dynamic import to enable tree-shaking: `const ELK = (await import('elkjs/lib/elk.bundled.js')).default`
    - Use NODE_DIMENSIONS from constants.ts for node width/height based on zoom tier

    **Full Detail Node** (`nodes/full-detail-node.tsx`):
    - React Flow custom node component using `memo` and `Handle` from @xyflow/react
    - Renders a rounded card (rounded-xl) with:
      - Colored left border (4px) using ENTITY_COLORS[entityType]
      - Background: `var(--elevated)` with opacity
      - Top row: Lucide icon (from ENTITY_ICONS) + entity name (truncated to 1 line)
      - Bottom row: entity type badge (small pill) + key property (e.g., ticket identifier, PR number)
    - Root node (depth=0): strong box-shadow glow using entity color at 40% opacity
    - Selected node: pulse-ring animation (CSS keyframe)
    - Hovered node: medium glow at 20% opacity
    - Dimmed state: opacity 0.3 with transition-opacity duration-300
    - Source and Target Handles positioned at center (invisible, for edge routing)
    - Use `'use client'` directive

    **Compact Pill Node** (`nodes/compact-pill-node.tsx`):
    - Small rounded-full pill (~120x32px)
    - Left: small colored dot (8px circle, entity color)
    - Right: short label (name truncated to ~15 chars)
    - Background: `var(--elevated)` with subtle border
    - Dimmed state: opacity 0.3
    - Source and Target Handles (invisible)

    **Glow Dot Node** (`nodes/glow-dot-node.tsx`):
    - Colored circle (24x24) filled with entity color
    - Box-shadow glow using `color-mix(in oklch, {entityColor} 50%, transparent)` for soft halo
    - Root node: larger glow radius (0 0 16px 4px)
    - Dimmed state: opacity 0.3
    - Source and Target Handles (invisible)
    - On hover: show tiny tooltip with name via CSS `::after` or a title attribute

    **Styled Edge** (`edges/styled-edge.tsx`):
    - Custom edge component using `getBezierPath` from @xyflow/react
    - Apply EDGE_STYLES based on `data.relationshipType` — match with string includes/startsWith:
      - If type includes 'authored' or 'created' → solid + arrow
      - If type includes 'mention' or 'reference' → dashed + arrow
      - If type includes 'block' or 'depends' → thick + red-tinted + arrow
      - Else → thin, muted, no arrow
    - Default state: low opacity (0.3)
    - Highlighted state (data.isHighlighted): full opacity + slightly thicker
    - On hover: show floating label at edge midpoint with relationship type text (use `EdgeLabelRenderer` from @xyflow/react)
    - Marker end: arrowclosed when hasArrow is true

    **Graph Controls** (`graph-controls.tsx`):
    - Floating pill bar positioned bottom-center of the graph canvas (absolute, bottom-4, left-1/2 transform)
    - Background: `var(--card)` with border, rounded-full, backdrop-blur
    - Buttons (using shadcn Button variant="ghost" size="icon"): ZoomIn, ZoomOut, Maximize2 (fit view), Search (command palette trigger placeholder)
    - MiniMap toggle button
    - Each button calls React Flow's `useReactFlow()` hook methods: `zoomIn()`, `zoomOut()`, `fitView()`
    - Filter chips row: one chip per entity type with colored dot + count, clickable to toggle filter (tracked via local state, passed up via callback prop `onFilterChange`)

    **GraphExplorer** (`graph-explorer.tsx`):
    - Main component: `export function GraphExplorer({ ticketIdentifier, className }: { ticketIdentifier: string; className?: string })`
    - `'use client'` directive
    - State management with useState:
      - `nodes`, `edges` (React Flow state via `useNodesState`, `useEdgesState`)
      - `loading`, `error` booleans
      - `hoveredNodeId: string | null`
      - `selectedNodeId: string | null`
      - `zoomTier: ZoomTier` (derived from viewport zoom)
      - `hiddenEntityTypes: Set<EntityType>` (filter state)
      - `showMiniMap: boolean`
    - On mount / ticketIdentifier change:
      1. Set loading=true
      2. Call `fetchGraphNeighborhood(ticketIdentifier)` from api.ts
      3. Transform API response nodes to React Flow Node[] format (with GraphNodeData)
      4. Transform API response edges to React Flow Edge[] format (with GraphEdgeData)
      5. Call `computeElkLayout(nodes, edges)` to get positioned nodes
      6. Set nodes/edges state, loading=false
    - Register `nodeTypes`: based on zoomTier state — when zoomTier changes, swap nodeTypes map:
      - 'full' → FullDetailNode for all
      - 'compact' → CompactPillNode for all
      - 'dot' → GlowDotNode for all
      Note: use `type` field on each node set to current zoom tier name so React Flow renders the correct component
    - Register `edgeTypes`: `{ default: StyledEdge }`
    - Viewport change handler via `onViewportChange`: compute zoomTier from viewport.zoom using getZoomTier(), update node types accordingly
    - Hover interaction:
      - `onNodeMouseEnter`: set hoveredNodeId, compute connected node IDs (from edges), set isDimmed=true on all unconnected nodes, set isHighlighted=true on connected edges
      - `onNodeMouseLeave`: clear hoveredNodeId, reset all isDimmed/isHighlighted
    - Click interaction: `onNodeClick` → set selectedNodeId (detail panel will be added in Plan 02)
    - Entity type filter: when hiddenEntityTypes changes, set `hidden: true` on filtered nodes and remove edges pointing to/from hidden nodes
    - Render:
      ```tsx
      <div className={cn('relative h-full w-full', className)}>
        <ReactFlow
          nodes={visibleNodes}
          edges={visibleEdges}
          nodeTypes={currentNodeTypes}
          edgeTypes={edgeTypes}
          onViewportChange={handleViewportChange}
          onNodeMouseEnter={handleNodeMouseEnter}
          onNodeMouseLeave={handleNodeMouseLeave}
          onNodeClick={handleNodeClick}
          fitView
          colorMode="dark"
          minZoom={0.1}
          maxZoom={4}
          proOptions={{ hideAttribution: true }}
        >
          {showMiniMap && <MiniMap />}
          <Background variant={BackgroundVariant.Dots} gap={20} size={1} />
        </ReactFlow>
        <GraphControls
          onZoomIn={() => reactFlowInstance.zoomIn()}
          onZoomOut={() => reactFlowInstance.zoomOut()}
          onFitView={() => reactFlowInstance.fitView()}
          onToggleMiniMap={() => setShowMiniMap(prev => !prev)}
          showMiniMap={showMiniMap}
          entityCounts={entityCounts}
          hiddenEntityTypes={hiddenEntityTypes}
          onFilterChange={setHiddenEntityTypes}
        />
        {loading && <GraphSkeleton />}
        {error && <GraphError message={error} onRetry={...} />}
        {!loading && nodes.length === 0 && <GraphEmpty />}
      </div>
      ```
    - Loading state (`GraphSkeleton`): inline sub-component with pulsing Skeleton circles at estimated positions (3-5 dots with connecting lines), centered
    - Empty state: "This ticket hasn't been processed yet" message with "Generate Context" CTA button (links to generation, optional — can be a simple message for now)
    - Error state: error message with retry button

    - Glow effects use CSS box-shadow with color-mix (not filters) per user decision
    - Match existing animation curves: `cubic-bezier(0.34, 1.56, 0.64, 1)`
