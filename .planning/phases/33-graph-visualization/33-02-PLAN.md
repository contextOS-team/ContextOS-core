      - Properties section: render all node.properties as key-value pairs in a definition list
      - Connections section heading: "Connections ({N})"
      - Connection rows: each row shows:
        - Colored dot for connected node's entity type
        - Connected node name (clickable)
        - Relationship type badge (small muted pill)
        - Direction arrow icon (ArrowRight for outgoing, ArrowLeft for incoming)
      - Clicking a connection row calls `onNavigateToNode(connectedNodeId)`
    - Slide-in animation from right (use `translate-x-full` to `translate-x-0` transition)

    **Update GraphExplorer** (`graph-explorer.tsx`):
    - Add state: `expandedNodeId: string | null` (for sidebar), `popoverNodeId: string | null` (for popover)
    - Update `onNodeClick` handler:
      1. Set `selectedNodeId` and `popoverNodeId` to clicked node ID
      2. Compute screen position of clicked node using `reactFlowInstance.flowToScreenPosition()`
    - Add `handleExpand` callback: sets `expandedNodeId = selectedNodeId`, clears `popoverNodeId`
    - Add `handleNavigateToNode(nodeId)` callback:
      1. Set `selectedNodeId` and `expandedNodeId` to nodeId
      2. Clear `popoverNodeId`
      3. Use `reactFlowInstance.setCenter(node.position.x, node.position.y, { zoom: 1.2, duration: 500 })` to smoothly pan to the node
      4. Update hover highlighting to focus on the new node
    - Add `handleClosePopover` and `handleCloseSidebar` callbacks
    - Compute `connections` array for DetailSidebar from current edges and nodes
    - Render NodePopover and DetailSidebar conditionally:

      ```tsx
      {popoverNodeId && (

          node={getNodeData(popoverNodeId)}
          position={popoverPosition}

          onClose={handleClosePopover}
          onExpand={handleExpand}
          onNavigateToNode={handleNavigateToNode}
        />
      )}
      {expandedNodeId && (
        <DetailSidebar
          node={getNodeData(expandedNodeId)}
          connections={getConnections(expandedNodeId)}
          onClose={handleCloseSidebar}
          onNavigateToNode={handleNavigateToNode}
        />
      )}
      ```
