# Plan 10-01: Sync State Management, SyncAdapter Protocol, and Structured Logging

## Goal

Replace the ad-hoc `workspace_integrations.config` JSONB sync state storage with a dedicated `sync_cursors` table, define a `SyncAdapter` protocol that all providers implement, and add structured logging with `sync_run_id` correlation across all sync operations.

## Must-Haves (Goal-Backward)

1. `sync_cursors` table exists with columns: workspace_id, provider, resource_type, cursor_type, cursor_value, records_synced, sync_status, last_sync_at, error_message
2. SyncAdapter protocol defines `full_sync()`, `handle_webhook()`, and `reconcile()` methods that all three providers implement
3. Every sync operation generates a UUID `sync_run_id` that appears in every log message for that run
4. Notion, Linear, and GitHub sync services read/write sync state from `sync_cursors` instead of JSONB config
5. Existing API endpoints and webhook handlers work unchanged (backward compatible)

## Context (from CONTEXT.md decisions)

**Sync State -- LOCKED:**
- Dedicated `sync_cursors` table replacing JSONB in `workspace_integrations.config`
- Columns: workspace_id, provider, resource_type, cursor_type, cursor_value, records_synced, sync_status, last_sync_at, error_message
- Structured logging with `sync_run_id` correlation -- generate UUID per sync run, thread through all log messages. Add provider + workspace_id to log context

**SyncAdapter Protocol -- LOCKED:**
- Methods: `full_sync()`, `handle_webhook()`, `reconcile()`
- Shared orchestration layer for scheduling, state management, error handling

## Existing Code Patterns

- `notion_sync.py` uses `_update_sync_config()` to merge JSONB into `workspace_integrations.config`
- `linear_sync.py` uses `_update_sync_status()` for same JSONB pattern
- `github_sync.py` uses `_update_repo_sync_status()` for per-repo JSONB
- All use `async_session()` for background task isolation
- All timestamps use `datetime.now(timezone.utc).replace(tzinfo=None)`

```sql
-- Dedicated sync state tracking table
-- Replaces ad-hoc JSONB in workspace_integrations.config
CREATE TABLE IF NOT EXISTS public.sync_cursors (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    workspace_id UUID NOT NULL REFERENCES public.workspaces(id),
    provider TEXT NOT NULL CHECK (provider IN ('linear', 'slack', 'github', 'notion', 'fathom')),
    resource_type TEXT NOT NULL DEFAULT 'default',
    cursor_type TEXT NOT NULL DEFAULT 'pagination',
    cursor_value TEXT,
    records_synced INTEGER NOT NULL DEFAULT 0,
    sync_status TEXT NOT NULL DEFAULT 'idle' CHECK (sync_status IN ('idle', 'syncing', 'complete', 'error')),
    last_sync_at TIMESTAMP WITHOUT TIME ZONE,
    error_message TEXT,
    created_at TIMESTAMP WITHOUT TIME ZONE NOT NULL DEFAULT now(),
    updated_at TIMESTAMP WITHOUT TIME ZONE NOT NULL DEFAULT now(),

    UNIQUE (workspace_id, provider, resource_type)
);

-- Trigger for updated_at
CREATE TRIGGER sync_cursors_updated_at
    BEFORE UPDATE ON public.sync_cursors
    FOR EACH ROW
    EXECUTE FUNCTION moddatetime(updated_at);

-- RLS
ALTER TABLE public.sync_cursors ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage their workspace sync cursors"
    ON public.sync_cursors
    FOR ALL
    USING (workspace_id IN (SELECT workspace_id FROM public.workspace_members WHERE user_id = auth.uid() AND deleted_at IS NULL));
```

```python
Provides a common interface for all provider sync services and shared

import uuid

from typing import Protocol, runtime_checkable

from sqlalchemy.dialects.postgresql import insert

logger = logging.getLogger(__name__)


@runtime_checkable
class SyncAdapter(Protocol):
    """Protocol defining the common sync interface for all providers.

    Every provider (Notion, Linear, GitHub, Slack) must implement these
    three methods for consistent sync orchestration.
    """

    provider: str

    async def full_sync(
        self, session: AsyncSession, workspace_id: uuid.UUID, **kwargs
    ) -> dict:
        """Run a full sync for the given workspace.

        Returns:
            Summary dict with provider-specific sync results.
        """
        ...

    async def handle_webhook(
        self, session: AsyncSession, workspace_id: uuid.UUID, payload: dict
    ) -> None:
        """Process a single webhook event for the given workspace."""
        ...

    async def reconcile(
        self, session: AsyncSession, workspace_id: uuid.UUID
    ) -> dict:
        """Reconcile local state with remote -- polling fallback.

        Catches missed webhook events by comparing local state with
        the provider API. Returns summary of changes found.
        """
        ...
```

2. **Sync state helpers** -- shared functions for reading/writing sync_cursors:

```python
def generate_sync_run_id() -> str:
    """Generate a unique sync run ID for log correlation."""
    return str(uuid.uuid4())


async def get_or_create_cursor(
    session: AsyncSession,
    workspace_id: uuid.UUID,
    provider: str,
    resource_type: str = "default",
) -> SyncCursor:
    """Get existing sync cursor or create a new one.

    Uses ON CONFLICT for safe concurrent access.
    """
    stmt = select(SyncCursor).where(
        SyncCursor.workspace_id == workspace_id,
        SyncCursor.provider == provider,
        SyncCursor.resource_type == resource_type,
    )
    result = await session.execute(stmt)
    cursor = result.scalar_one_or_none()

    if cursor is None:
        cursor = SyncCursor(
            workspace_id=workspace_id,
            provider=provider,
            resource_type=resource_type,
        )
        session.add(cursor)
        await session.flush()

    return cursor


async def update_cursor_status(
    session: AsyncSession,
    workspace_id: uuid.UUID,
    provider: str,
    resource_type: str,
    *,
    sync_status: str,
    records_synced: int | None = None,
    cursor_value: str | None = None,
    error_message: str | None = None,
) -> None:
    """Update sync cursor state.

    Sets last_sync_at when status is 'complete'.
    Clears error_message on non-error statuses.
    """
    cursor = await get_or_create_cursor(
        session, workspace_id, provider, resource_type
    )
    cursor.sync_status = sync_status

    if records_synced is not None:
        cursor.records_synced = records_synced
    if cursor_value is not None:
        cursor.cursor_value = cursor_value

    if sync_status == "complete":
        cursor.last_sync_at = datetime.now(timezone.utc).replace(tzinfo=None)
        cursor.error_message = None
    elif sync_status == "error":
        cursor.error_message = error_message
    else:
        cursor.error_message = None

    await session.flush()


async def get_cursor_status(
    session: AsyncSession,
    workspace_id: uuid.UUID,
    provider: str,
    resource_type: str = "default",
) -> dict:
    """Get current sync cursor status as a dict.

    Returns empty dict with idle status if no cursor exists.
    """
    stmt = select(SyncCursor).where(
        SyncCursor.workspace_id == workspace_id,
        SyncCursor.provider == provider,
        SyncCursor.resource_type == resource_type,
    )
    result = await session.execute(stmt)
    cursor = result.scalar_one_or_none()

    if cursor is None:
        return {
            "sync_status": "idle",
            "records_synced": 0,
            "last_sync_at": None,
            "error_message": None,
        }

    return {
        "sync_status": cursor.sync_status,
        "records_synced": cursor.records_synced,
        "last_sync_at": cursor.last_sync_at.isoformat() if cursor.last_sync_at else None,
        "error_message": cursor.error_message,
        "cursor_value": cursor.cursor_value,
    }
```

3. **Structured logging context manager** for sync runs:

```python
import contextvars

_sync_run_id_var: contextvars.ContextVar[str] = contextvars.ContextVar(
    "sync_run_id", default=""
)


class SyncRunLogger:
    """Context manager that sets sync_run_id in log context.

    Usage:
        async with SyncRunLogger("notion", workspace_id) as srl:
            srl.info("Starting sync")
            ...
    """

    def __init__(self, provider: str, workspace_id: uuid.UUID) -> None:
        self.provider = provider
        self.workspace_id = str(workspace_id)
        self.run_id = generate_sync_run_id()
        self._logger = logging.getLogger(f"sync.{provider}")

    async def __aenter__(self) -> "SyncRunLogger":
        _sync_run_id_var.set(self.run_id)
        self.info("Sync run started")
        return self

    async def __aexit__(self, *args) -> None:
        self.info("Sync run ended")
        _sync_run_id_var.set("")

    def _extra(self) -> dict:
        return {
            "sync_run_id": self.run_id,
            "provider": self.provider,
            "workspace_id": self.workspace_id,
        }

    def info(self, msg: str, **kwargs) -> None:
        self._logger.info(msg, extra={**self._extra(), **kwargs})

    def warning(self, msg: str, **kwargs) -> None:
        self._logger.warning(msg, extra={**self._extra(), **kwargs})

    def error(self, msg: str, **kwargs) -> None:
        self._logger.error(msg, extra={**self._extra(), **kwargs})

    def exception(self, msg: str, **kwargs) -> None:
        self._logger.exception(msg, extra={**self._extra(), **kwargs})
```
