# Plan 10-02: Embedding Pipeline Optimization

## Goal

Decouple embedding generation from sync via Redis Streams so syncs complete fast, batch 20-50 texts per OpenAI API call, normalize whitespace before content hashing for significance filtering, and add model version tracking to the embeddings table for future selective re-embedding.

## Must-Haves (Goal-Backward)

1. Sync services push embedding jobs to Redis Streams instead of calling OpenAI inline -- syncs return without waiting for embedding generation
2. A background worker consumes from the Redis Stream and processes embeddings asynchronously
3. OpenAI embedding API calls batch 20-50 texts per request (OpenAI supports list inputs natively)
4. Content hash computation normalizes whitespace/formatting before SHA-256 so trivial edits (spacing, line breaks) do not trigger re-embedding
5. `embeddings` table has `model_name` and `model_version` columns for selective re-embedding on model upgrades
6. Existing `queue_embedding_generation()` function is retained for use by the embedding worker; sync call sites will be rewired to use `enqueue_embedding_job()` in Plan 10-03

## Context (from CONTEXT.md decisions)

**Embedding Pipeline -- LOCKED:**
- Decouple embedding generation from sync via Redis Streams -- sync completes fast, embedding workers process asynchronously from queue
- Batch 20-50 texts per OpenAI embedding API call instead of one-at-a-time (OpenAI supports list inputs natively)
- Normalize whitespace and formatting before computing content hash for significance filtering -- trivial edits (spacing, line breaks) should not trigger re-embedding
- Track embedding model version -- add model_name and model_version columns to embeddings table for selective re-embedding on model upgrades

## Existing Code Patterns

- `embedding.py` has `queue_embedding_generation()` -- loops one-at-a-time, calls OpenAI per item, upserts each
- `_compute_content_hash()` does raw SHA-256 on text_content.encode("utf-8") (no normalization)
- `generate_embedding()` calls `client.embeddings.create()` with single `input` string
- OpenAI API accepts `input` as a list of strings and returns `.data[i].embedding` in order
- Redis already in docker-compose as `redis:7-alpine` on port 6379
- `REDIS_URL` already in Settings: `redis://localhost:6379/0`
- `redis` already in pyproject.toml dependencies

import re

def _normalize_for_hash(text_content: str) -> str:
    """Normalize text for content hash comparison.

    Collapses all whitespace sequences (spaces, tabs, newlines) into
    single spaces and strips leading/trailing whitespace. This prevents
    trivial formatting changes from triggering re-embedding.

    Args:
        text_content: Raw text content.

    Returns:
        Normalized text string.
    """
    return re.sub(r'\s+', ' ', text_content).strip()


def _compute_content_hash(text_content: str) -> str:
    """Compute SHA-256 hash of normalized content for change detection.

    Normalizes whitespace before hashing so trivial formatting edits
    (spacing, line breaks) do not trigger re-embedding.
    """
    normalized = _normalize_for_hash(text_content)
    return hashlib.sha256(normalized.encode("utf-8")).hexdigest()
```

BATCH_SIZE = 25  # 20-50 per CONTEXT.md decision; 25 is a safe middle ground

@observe(name="generate_embeddings_batch")
async def generate_embeddings_batch(texts: list[str]) -> list[list[float]]:
    """Generate 768-dimensional embeddings for multiple texts in one API call.

    OpenAI text-embedding-3-small supports list inputs natively.
    Results are returned in the same order as the input texts.

    Args:
        texts: List of text strings to embed.

    Returns:
        List of 768-dimensional embedding vectors (same order as input).
    """
    if not texts:
        return []

    truncated = [t[:MAX_INPUT_CHARS] if t.strip() else "" for t in texts]
    client = _get_openai_client()
    response = await client.embeddings.create(
        model="text-embedding-3-small",
        input=truncated,
        dimensions=768,
    )
    # OpenAI returns data sorted by index
    sorted_data = sorted(response.data, key=lambda d: d.index)
    return [list(d.embedding) for d in sorted_data]
```

**2. Refactor `queue_embedding_generation()` to use batching:**

Replace the one-at-a-time loop with batch processing:

```python
async def queue_embedding_generation(
    session: AsyncSession,
    workspace_id: UUID,
    source_type: str,
    source_ids: list[UUID],
) -> None:
    """Generate and store embeddings for the given source records.

    Now processes records in batches of BATCH_SIZE for efficiency.
    """
    if source_type not in SOURCE_TYPE_MAP:
        logger.warning("Unknown source_type for embedding: %s", source_type)
        return

    model_cls, extract_text = SOURCE_TYPE_MAP[source_type]

    # Collect records that need embedding
    pending: list[tuple[UUID, str, str]] = []  # (source_id, text, content_hash)

    for source_id in source_ids:
        try:
            stmt = select(model_cls).where(model_cls.id == source_id)
            result = await session.execute(stmt)
            record = result.scalar_one_or_none()
            if record is None:
                continue

            text_content = extract_text(record)
            if not text_content or not text_content.strip():
                continue

            content_hash = _compute_content_hash(text_content)

            # Check existing hash
            existing_stmt = select(Embedding.content_hash).where(
                Embedding.source_type == source_type,
                Embedding.source_id == source_id,
            )
            existing_result = await session.execute(existing_stmt)
            existing_hash = existing_result.scalar_one_or_none()

            if existing_hash == content_hash:
                continue

            pending.append((source_id, text_content, content_hash))
        except Exception:
            logger.exception(
                "Failed to prepare embedding for %s %s", source_type, source_id
            )

    if not pending:
        return

    # Process in batches
    for i in range(0, len(pending), BATCH_SIZE):
        batch = pending[i:i + BATCH_SIZE]
        texts = [item[1] for item in batch]

        try:
            embeddings = await generate_embeddings_batch(texts)
        except Exception:
            logger.exception(
                "Batch embedding generation failed for %s (batch %d)",
                source_type, i // BATCH_SIZE,
            )
            continue

        for (source_id, _, content_hash), embedding_vector in zip(batch, embeddings):
            try:
                upsert_stmt = (
                    insert(Embedding)
                    .values(
                        workspace_id=workspace_id,
                        source_type=source_type,
                        source_id=source_id,
                        content_hash=content_hash,
                        embedding=embedding_vector,
                        model_name=EMBEDDING_MODEL_NAME,
                        model_version=EMBEDDING_MODEL_VERSION,
                    )
                    .on_conflict_do_update(
                        constraint="embeddings_source_type_source_id_key",
                        set_={
                            "content_hash": content_hash,
                            "embedding": embedding_vector,
                            "model_name": EMBEDDING_MODEL_NAME,
                            "model_version": EMBEDDING_MODEL_VERSION,
                            "deleted_at": None,
                        },
                    )
                )
                await session.execute(upsert_stmt)
                logger.info(
                    "Generated embedding for %s %s (hash=%s...)",
                    source_type, source_id, content_hash[:12],
                )
            except Exception:
                logger.exception(
                    "Failed to upsert embedding for %s %s",
                    source_type, source_id,
                )
```

**3. Create `backend/src/services/embedding_worker.py` -- Redis Streams consumer:**

```python
"""Asynchronous embedding worker consuming from Redis Streams.

Reads embedding jobs from a Redis Stream and processes them in batches.
Sync services push jobs via enqueue_embedding_job() instead of calling
queue_embedding_generation() directly (for async decoupling).

Usage:
    # From sync services:
    await enqueue_embedding_job(workspace_id, source_type, source_ids)

    # Worker process (run as background task or standalone):
    await run_embedding_worker()
"""

import asyncio
import json
import logging
from uuid import UUID

import redis.asyncio as aioredis

from src.config import get_settings
from src.db import async_session
from src.services.embedding import queue_embedding_generation

logger = logging.getLogger(__name__)

STREAM_KEY = "embedding:jobs"
GROUP_NAME = "embedding-workers"
CONSUMER_NAME = "worker-1"
BATCH_READ_COUNT = 10  # Number of stream messages to read at once
BLOCK_MS = 5000  # Block for 5s waiting for new messages


def _get_redis() -> aioredis.Redis:
    """Create a Redis async client from settings."""
    settings = get_settings()
    return aioredis.from_url(settings.REDIS_URL, decode_responses=True)


async def _ensure_consumer_group(r: aioredis.Redis) -> None:
    """Create the consumer group if it doesn't exist."""
    try:
        await r.xgroup_create(STREAM_KEY, GROUP_NAME, id="0", mkstream=True)
    except aioredis.ResponseError as e:
        if "BUSYGROUP" not in str(e):
            raise


async def enqueue_embedding_job(
    workspace_id: UUID,
    source_type: str,
    source_ids: list[UUID],
) -> None:
    """Push an embedding job to the Redis Stream.

    Called by sync services instead of queue_embedding_generation()
    for async decoupling. The embedding worker will pick up the job
    and process it asynchronously.

    Args:
        workspace_id: Workspace the sources belong to.
        source_type: Type of source (e.g. 'notion_page').
        source_ids: List of source record UUIDs.
    """
    if not source_ids:
        return

    r = _get_redis()
    try:
        payload = json.dumps({
            "workspace_id": str(workspace_id),
            "source_type": source_type,
            "source_ids": [str(sid) for sid in source_ids],
        })
        await r.xadd(STREAM_KEY, {"data": payload})
        logger.info(
            "Enqueued embedding job: type=%s count=%d workspace=%s",
            source_type, len(source_ids), workspace_id,
        )
    finally:
        await r.aclose()


async def _process_message(message_data: dict) -> None:
    """Process a single embedding job from the stream."""
    raw = message_data.get("data", "{}")
    try:
        job = json.loads(raw)
    except json.JSONDecodeError:
        logger.error("Invalid JSON in embedding job: %s", raw[:200])
        return

    workspace_id = UUID(job["workspace_id"])
    source_type = job["source_type"]
    source_ids = [UUID(sid) for sid in job["source_ids"]]

    async with async_session() as session:
        await queue_embedding_generation(
            session, workspace_id, source_type, source_ids
        )
        await session.commit()


async def run_embedding_worker() -> None:
    """Run the embedding worker loop.

    Reads from the Redis Stream consumer group, processes embedding
    jobs, and acknowledges completed messages. Runs indefinitely.
    """
    r = _get_redis()
    await _ensure_consumer_group(r)

    logger.info("Embedding worker started (stream=%s, group=%s)", STREAM_KEY, GROUP_NAME)

    try:
        while True:
            try:
                messages = await r.xreadgroup(
                    GROUP_NAME,
                    CONSUMER_NAME,
                    {STREAM_KEY: ">"},
                    count=BATCH_READ_COUNT,
                    block=BLOCK_MS,
                )

                if not messages:
                    continue

                for stream_name, entries in messages:
                    for msg_id, msg_data in entries:
                        try:
                            await _process_message(msg_data)
                            await r.xack(STREAM_KEY, GROUP_NAME, msg_id)
                        except Exception:
                            logger.exception(
                                "Failed to process embedding job %s", msg_id
                            )

            except Exception:
                logger.exception("Embedding worker loop error, retrying in 5s")
                await asyncio.sleep(5)

    finally:
        await r.aclose()
```
