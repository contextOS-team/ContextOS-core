# Plan 10-03: Concurrency Controls, HTTP/2, Jittered Retry, Connection Pools, and Incremental Sync

## Goal

Add per-provider asyncio.Semaphore concurrency limits, enable HTTP/2 on all httpx clients, add random jitter to retry backoff, configure explicit connection pool limits, implement metadata-only incremental sync (skip body refetch when only metadata changed), and add a 15-minute polling fallback scheduler.

## Must-Haves (Goal-Backward)

1. Each provider has an asyncio.Semaphore limiting concurrent API calls: Notion(3), GitHub(10), Linear(5)
2. All httpx.AsyncClient instances use HTTP/2 (`http2=True`)
3. All retry backoff logic includes random jitter: `wait *= 0.5 + random.random()` (50-150% of base delay)
4. Connection pool limits configured per provider: Notion max_connections=10/keepalive=5, GitHub max_connections=30/keepalive=20, all keepalive_expiry=30
5. Notion sync skips body content refetch when only metadata changed (compares `last_edited_time`)
6. A polling fallback function exists that can be scheduled every 15 minutes to catch missed webhook events
7. `backend/src/main.py` lifespan launches `run_embedding_worker()` and `run_polling_fallback()` as background tasks on startup with graceful cancellation on shutdown
8. All sync call sites (`notion_sync.py`, `notion.py` `_run_sync()`, `linear_sync.py`, `github_sync.py`, `sync_scheduler.py`) call `enqueue_embedding_job()` instead of `queue_embedding_generation()` directly

## Context (from CONTEXT.md decisions)

**Concurrency & Rate Limits -- LOCKED:**
- asyncio.Semaphore per provider: Notion Semaphore(3), GitHub Semaphore(10), Linear Semaphore(5)
- Enable HTTP/2 for all httpx API clients (requires httpx[http2] / h2 dependency)
- Add random jitter to retry backoff: wait *= 0.5 + random.random() for 50-150% of base delay
- Configure explicit httpx connection pool limits per provider:
  - Notion: max_keepalive=5, max_connections=10 (low rate limit)
  - GitHub: max_keepalive=20, max_connections=30 (higher throughput)
  - All: keepalive_expiry=30s

**Incremental Sync -- LOCKED:**
- Webhook-first with polling fallback for all providers that support webhooks
- Polling fallback runs every 15 minutes to catch missed webhook events
- Skip body content refetch when only metadata changed -- compare last_edited_time to decide if full content fetch is needed

## Existing Code Patterns

- `NotionClient._request()` has exponential backoff: `delay = 1.0` then `delay *= 2`
- `NotionClient.__init__()` creates `httpx.AsyncClient(headers=..., timeout=30.0)` -- no pool or HTTP/2 config
- `linear_graphql.py` has its own retry loop (exponential backoff on 429)
- `github_common.py` has `check_rate_limit()` for 403 rate-limit handling
- Notion router `_run_sync()` fetches content for ALL pages every time (no incremental check)
- All sync services follow the `async_session()` background task isolation pattern

async def _request(self, method: str, path: str, **kwargs) -> dict:

    for attempt in range(MAX_RETRIES + 1):
        async with _notion_semaphore:
            response = await self._client.request(method, url, **kwargs)

        if response.status_code == 429:
            if attempt < MAX_RETRIES:

            raise NotionClientError(
                f"Notion API error {response.status_code}: {response.text}"
            )

    raise NotionClientError("Unexpected retry loop exit")

**2. Polling fallback scheduler** -- Create `backend/src/services/sync_scheduler.py`:

```python
"""Polling fallback scheduler for catching missed webhook events.

Runs reconciliation checks every 15 minutes for all connected providers
to catch webhook deliveries that were lost or failed.

Per CONTEXT.md: Webhook-first with polling fallback for all providers
that support webhooks (Notion, GitHub, Linear).
"""

import asyncio
import logging
from uuid import UUID

from sqlmodel import select

from src.db import async_session
from src.models.integration import Provider, WorkspaceIntegration
from src.services.sync_adapter import SyncRunLogger, update_cursor_status

logger = logging.getLogger(__name__)

POLL_INTERVAL_SECONDS = 15 * 60  # 15 minutes per CONTEXT.md decision


async def _get_connected_workspaces(provider: Provider) -> list[UUID]:
    """Get all workspace IDs with a connected integration for the given provider."""
    async with async_session() as session:
        stmt = select(WorkspaceIntegration.workspace_id).where(
            WorkspaceIntegration.provider == provider,
            WorkspaceIntegration.status == "connected",
        )
        result = await session.execute(stmt)
        return [row[0] for row in result.fetchall()]


async def reconcile_notion(workspace_id: UUID) -> None:
    """Polling fallback for Notion: check for pages updated since last sync.

    Fetches the search API and compares last_edited_time against stored
    notion_updated_at to find pages that changed but didn't trigger a webhook.
    """
    from src.services.notion_oauth import get_valid_access_token
    from src.services.notion_client import NotionClient
    from src.services.notion_sync import sync_single_page
    from src.services.embedding_worker import enqueue_embedding_job
    import src.config as config_module

    settings = config_module.get_settings()

    async with SyncRunLogger("notion", workspace_id) as srl:
        try:
            async with async_session() as session:
                # Get any user_id for this workspace
                from src.models.user import WorkspaceMember
                stmt = select(WorkspaceMember.user_id).where(
                    WorkspaceMember.workspace_id == workspace_id,
                    WorkspaceMember.deleted_at.is_(None),
                ).limit(1)
                result = await session.execute(stmt)
                user_id = result.scalar_one_or_none()

                if user_id is None:
                    srl.warning("No active user found for workspace, skipping reconcile")
                    return

                access_token = await get_valid_access_token(
                    session, workspace_id, user_id, settings
                )

            async with NotionClient(access_token) as client:
                # Fetch recent pages (just first page of search results)
                response = await client.search_pages(page_size=100)
                pages = response.get("results", [])

                updated_count = 0
                async with async_session() as session:
                    from src.models.notion import NotionPage
                    from sqlmodel import select as sm_select

                    for page_data in pages:
                        notion_id = page_data.get("id", "")
                        notion_last_edited = page_data.get("last_edited_time")

                        # Check if we need to re-sync this page
                        check_stmt = sm_select(NotionPage.notion_updated_at).where(
                            NotionPage.workspace_id == workspace_id,
                            NotionPage.notion_id == notion_id,
                        )
                        check_result = await session.execute(check_stmt)
                        stored_updated = check_result.scalar_one_or_none()

                        if notion_last_edited and stored_updated:
                            from src.routers.notion import _parse_notion_datetime
                            new_updated = _parse_notion_datetime(notion_last_edited)
                            if new_updated and stored_updated >= new_updated:
                                continue  # Up to date

                        # Page needs re-sync
                        page_record = await sync_single_page(
                            session, client, workspace_id, page_data
                        )
                        await enqueue_embedding_job(
                            workspace_id, "notion_page", [page_record.id]
                        )
                        updated_count += 1

                    if updated_count > 0:
                        await session.commit()
                        srl.info("Reconciled %d Notion pages", updated_count)
                    else:
                        srl.info("No Notion pages need reconciliation")

        except Exception:
            srl.exception("Notion reconciliation failed")


async def run_polling_fallback() -> None:
    """Run the polling fallback loop indefinitely.

    Checks all connected providers every 15 minutes for missed webhook
    events. Designed to be started as a background task on application startup.
    """
    logger.info("Polling fallback scheduler started (interval=%ds)", POLL_INTERVAL_SECONDS)

    while True:
        try:
            # Notion reconciliation
            notion_workspaces = await _get_connected_workspaces(Provider.NOTION)
            for ws_id in notion_workspaces:
                try:
                    await reconcile_notion(ws_id)
                except Exception:
                    logger.exception(
                        "Notion reconciliation failed for workspace %s", ws_id
                    )

            # Linear and GitHub reconciliation stubs
            # (can be implemented when those providers have
            # incremental sync support via updatedAt filters)

        except Exception:
            logger.exception("Polling fallback scheduler error")

        await asyncio.sleep(POLL_INTERVAL_SECONDS)
```

<title>Wire startup of embedding worker and polling fallback in main.py lifespan</title>
<what>
Update `backend/src/main.py` to launch `run_embedding_worker()` and `run_polling_fallback()` as background asyncio tasks on application startup, with graceful cancellation on shutdown. Without this, both coroutines are dead code.

**Update the existing `lifespan()` function in `backend/src/main.py`:**

```python
@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    """Application lifespan handler for startup/shutdown."""
    import asyncio
    from src.services.embedding_worker import run_embedding_worker
    from src.services.sync_scheduler import run_polling_fallback

    # Startup: launch background workers
    embedding_task = asyncio.create_task(run_embedding_worker())
    polling_task = asyncio.create_task(run_polling_fallback())

    logger.info("Background workers started: embedding_worker, polling_fallback")

    yield

    # Shutdown: cancel background workers gracefully
    embedding_task.cancel()
    polling_task.cancel()

    for task in [embedding_task, polling_task]:
        try:
            await task
        except asyncio.CancelledError:
            pass

    logger.info("Background workers stopped")

    # Dispose the engine to close all connections
    from src.db import engine
    await engine.dispose()
```

Add `import logging` and `logger = logging.getLogger(__name__)` at the top of the file if not already present.

**Key design points:**
- Uses `asyncio.create_task()` so workers run in the background event loop
- `CancelledError` is caught during shutdown so the app exits cleanly
- Both workers have their own internal error handling (retry loops), so unhandled exceptions from `create_task` are unlikely
- Engine disposal is preserved from the existing shutdown logic
