    1. async process_single_content(session, client, workspace_id, content, source_type, source_node_id, author_user_id=None, bot_id=None) -> dict:
       - Returns stats dict: {"extracted": 0, "skipped_filter": 0, "skipped_dedup": 0, "errors": 0, "decisions": 0, "blockers": 0}
