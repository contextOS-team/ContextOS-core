<task type="auto">
  <name>Task 2: API key service and all backend endpoints</name>
  <files>backend/src/services/api_key.py, backend/src/routers/workspaces.py, backend/src/services/workspace.py</files>
  <action>
Create `backend/src/services/api_key.py` with these functions:

1. `generate_api_key() -> tuple[str, str, str]`: Generate a random API key using `secrets.token_hex(32)`. Return `(full_key, prefix, hash)` where full_key is `cos_{raw}`, prefix is `cos_{raw[:8]}`, hash is `hashlib.sha256(full_key.encode()).hexdigest()`.

2. `async create_api_key(session, workspace_id, created_by, name) -> tuple[ApiKey, str]`: Call generate_api_key(), create ApiKey row, return (model, full_key). The full key is only available at creation time.

3. `async list_api_keys(session, workspace_id) -> list[ApiKey]`: Return all non-revoked keys for the workspace, ordered by created_at DESC.

4. `async revoke_api_key(session, workspace_id, key_id) -> ApiKey | None`: Set `revoked_at = now()` on the key. Return None if key not found or already revoked. Verify workspace_id matches to prevent cross-workspace revocation.

Extend `backend/src/services/workspace.py` with:

5. `async update_workspace_name(session, workspace_id, name) -> Workspace`: Update workspace.name, commit, refresh, return updated workspace. Validate name is 1-50 chars (raise ValueError if not).

6. `async list_workspace_members(session, workspace_id) -> list[dict]`: Join `workspace_members` with `profiles` to return list of dicts with user_id, full_name, email, role, created_at. Filter where deleted_at IS NULL.

Extend `backend/src/routers/workspaces.py` with 5 new endpoints on the existing router (prefix `/api/workspaces`):

- `POST /current/api-keys` -- accepts `{"name": str}`, calls create_api_key, returns full key response with `key` field (shown once only). Validate name is non-empty and max 50 chars.
- `GET /current/api-keys` -- calls list_api_keys, returns `{"keys": [...]}` with id, name, key_prefix, created_at (no full key ever returned here).
- `DELETE /current/api-keys/{key_id}` -- calls revoke_api_key, returns `{"status": "revoked"}`. Return 404 if key not found.
- `PATCH /current` -- accepts `{"name": str}`, calls update_workspace_name, returns `{"id", "name", "slug", "created_at"}`. Return 400 for validation errors.
- `GET /current/members` -- calls list_workspace_members, returns `{"members": [...]}`.

All endpoints use `user: UserContext = Depends(get_current_user)` and `session: AsyncSession = Depends(get_session)`. Use Pydantic models for request bodies (e.g., `CreateApiKeyRequest(BaseModel): name: str`).

Import the new service in the router. Do NOT modify main.py -- the workspaces router is already registered.
