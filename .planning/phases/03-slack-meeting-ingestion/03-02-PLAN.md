**Channel service (backend/src/services/slack_channels.py):**

1. `async def list_channels(session, workspace_id)` -> list[dict]:
   - Read bot token from Vault via `slack_oauth.get_bot_token(session, workspace_id)`.
   - Call Slack Web API `https://slack.com/api/conversations.list` via httpx with:
     - `types=public_channel,private_channel` (per user decision: show public + private where bot is invited)
     - `exclude_archived=true`
     - `limit=1000` (single page for v1 -- per Claude's discretion for pagination)
   - If response has `response_metadata.next_cursor`, paginate by calling again with `cursor` parameter. Collect all channels across pages.
   - Respect Slack `Retry-After` header on 429 responses (per user decision). Sleep and retry.
   - Return list of `{"id": channel_id, "name": channel_name, "is_private": bool, "num_members": int}` dicts.
   - Also store the fetched channel list in workspace_integrations.config JSONB under key `available_channels` for caching (so UI doesn't need to hit Slack API on every page load).

2. `async def get_selected_channels(session, workspace_id)` -> list[str]:
   - Read `selected_channels` from workspace_integrations.config JSONB for provider="slack".
   - Return list of channel IDs. Returns empty list if none selected.

3. `async def save_channel_selection(session, workspace_id, channel_ids: list[str])`:
   - Update workspace_integrations.config JSONB: set `selected_channels` to the provided channel_ids list.
   - Commit.

4. `async def is_channel_monitored(session, workspace_id, channel_id)` -> bool:
   - Check if channel_id is in the selected_channels list. Used by slack_events.py to filter.

**Fathom service (backend/src/services/fathom.py):**

1. `FATHOM_API_BASE = "https://api.fathom.video/v1"` (or appropriate Fathom API base URL -- verify via Fathom docs at runtime, use this as default).

2. `async def connect_fathom(session, workspace_id, api_key)`:
   - Validate the API key by making a test call to Fathom API (e.g., list recent calls).
   - If valid, store the API key in Vault using `vault.store_token(session, f"fathom_{workspace_id}_api_key", api_key)`.
   - Upsert WorkspaceIntegration with provider="fathom", status="connected".
   - Return success/team info if available.

3. `async def disconnect_fathom(session, workspace_id)`:
   - Delete Vault secret.
   - Mark WorkspaceIntegration as disconnected.

4. `async def get_fathom_api_key(session, workspace_id)` -> str:
   - Read from Vault. Raise error if not found.

5. `async def poll_transcripts(session, workspace_id)`:
   - Read API key from Vault.
   - Call Fathom API to list recent calls/recordings (GET /calls or equivalent).
   - Handle pagination via cursor if Fathom API supports it (per Claude's discretion).
   - For each call/recording:
     - Check if already ingested (query meeting_transcripts where raw_data contains matching fathom_id).
     - If transcript is still processing (no content), skip and log. Per user decision: retry on next poll cycle.
     - Extract: title, participants, meeting_date, duration.
     - Fetch full transcript content with speaker segmentation.
     - Upsert MeetingTranscript record.
     - For each speaker turn in the transcript:
       - Create MeetingSegment with speaker_name, text, start_time_seconds, end_time_seconds.
     - Queue embedding generation for the transcript (source_type="meeting_transcript").
   - Store last_poll_at in workspace_integrations.config JSONB for provider="fathom".
   - Respect rate limits (Retry-After header).

6. `async def get_fathom_status(session, workspace_id)` -> dict:
   - Query WorkspaceIntegration for provider="fathom".
   - Return status, last_poll_at from config.
