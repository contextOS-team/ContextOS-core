    **code_index_worker.py:**
    Create a Redis Streams consumer for code indexing jobs, following the exact pattern of embedding_worker.py:

    ```python
    STREAM_KEY = "code_index:jobs"
    GROUP_NAME = "code-index-workers"
    CONSUMER_NAME = "worker-1"
    BATCH_READ_COUNT = 5  # Fewer than embedding worker -- indexing is heavier
    BLOCK_MS = 10000  # 10s block (indexing happens less frequently)
    ```

    1. `async def enqueue_code_index_job(workspace_id: UUID, repo_full_name: str) -> None` — Push a job to the Redis Stream. Same pattern as `enqueue_embedding_job()`: create Redis connection, xadd, close. Payload: `{"workspace_id": str, "repo_full_name": str}`.

    2. `async def enqueue_workspace_index_job(workspace_id: UUID) -> None` — Push a "full workspace" job. Payload: `{"workspace_id": str, "repo_full_name": "__all__"}`. The worker treats `__all__` as a signal to call `index_workspace_repos()` instead of `index_repo()`.

    3. `async def _process_index_message(message_data: dict) -> None` — Parse the job, create a session via `async_session()`, call `index_repo()` or `index_workspace_repos()` depending on `repo_full_name`. After indexing, enqueue embedding jobs for all new/updated code chunks via `enqueue_embedding_job()` with source_type="code_chunk".

    4. `async def run_code_index_worker() -> None` — Same loop pattern as `run_embedding_worker()`: ensure consumer group, xreadgroup loop, process messages, xack. Handle CancelledError for graceful shutdown.

    **github_webhook.py changes:**

       - Requires JWT auth (get_current_user)

       - Response: `{"status": "accepted", "repo": repo_full_name}`
       - Return 404 if repo not monitored
