    **GraphQL client (backend/src/services/linear_graphql.py):**
    Create a reusable async GraphQL client for Linear's API (`https://api.linear.app/graphql`). Per user decision: raw httpx, no SDK.

    Class `LinearGraphQLClient`:
    - `__init__(self, access_token: str)` -- stores token, creates httpx.AsyncClient with auth header `Authorization: {access_token}` (Linear uses bare token, not "Bearer"). Set timeout to 30 seconds.
    - `async query(self, graphql_query: str, variables: dict | None = None) -> dict` -- POST to Linear GraphQL endpoint. Handle errors: raise `LinearAPIError` on non-200, parse GraphQL errors from response body. Implement exponential backoff on 429 (per user decision): start at 1s, max 3 retries, multiply by 2. Read `Retry-After` header if present.
    - `async fetch_all_pages(self, graphql_query: str, variables: dict, connection_path: list[str]) -> list[dict]` -- Cursor-based pagination helper. Takes a query with `$after: String` variable and a path to the connection object (e.g., ["team", "issues"]). Iterates `pageInfo.hasNextPage` / `pageInfo.endCursor`. Collects all `nodes` across pages. Returns flat list.
    - `async close(self)` -- close the httpx client.

    Also define `class LinearAPIError(Exception)` with status_code and message.

    **Ticket models (backend/src/models/ticket.py):**
    Create SQLModel table models following BaseModel pattern:

    - `LinearTicket(BaseModel, table=True)` -- maps to public.linear_tickets. Fields matching the schema: workspace_id (UUID, FK), linear_id (str), identifier (str), title (str), description (str | None), status (str | None), priority (int | None), assignee_name (str | None), team_name (str | None), project_name (str | None), labels (list[str] | None via sa_column ARRAY), linear_created_at (datetime | None), linear_updated_at (datetime | None), raw_data (dict via sa_column JSONB).

    - `LinearComment(BaseModel, table=True)` -- maps to public.linear_comments. Fields: workspace_id (UUID, FK), ticket_id (UUID, FK to linear_tickets.id), linear_id (str), body (str), author_name (str | None), linear_created_at (datetime | None), linear_updated_at (datetime | None).

    Update `backend/src/models/__init__.py` to re-export these.

    **Sync service (backend/src/services/linear_sync.py):**
    Implements the sync orchestration. Per user decisions: pull all tickets except Cancelled, include Done/Completed for historical context.

    Functions:
    1. `async fetch_teams(access_token: str) -> list[dict]` -- Query Linear GraphQL: `{ teams { nodes { id name key } } }`. Returns list of team dicts for the team picker UI.

    2. `async sync_tickets_for_teams(session: AsyncSession, workspace_id: UUID, user_id: UUID, team_ids: list[str], settings: Settings) -> dict` -- Main sync entry point:
       - Get valid access token via `linear_oauth.get_valid_access_token()`
       - For each team_id, fetch all issues (except state type "canceled") using paginated GraphQL query:
         ```graphql
         query($teamId: String!, $after: String) {
           team(id: $teamId) {
             issues(first: 50, after: $after, filter: { state: { type: { nin: ["canceled"] } } }) {
               pageInfo { hasNextPage endCursor }
               nodes {
                 id identifier title description
                 state { name type }
                 priority
                 assignee { name }
                 team { name }
                 project { name }
                 labels { nodes { name } }
                 comments { nodes { id body user { name } createdAt updatedAt } }
                 createdAt updatedAt
               }
             }
           }
         }
         ```
       - Upsert each ticket into linear_tickets (ON CONFLICT workspace_id, linear_id DO UPDATE)
       - Upsert each comment into linear_comments (ON CONFLICT workspace_id, linear_id DO UPDATE)
       - After all tickets stored, call `queue_embedding_generation()` with the list of ticket IDs
       - Store selected team_ids in workspace_integrations.config jsonb as `{"synced_teams": [...]}`
       - Return summary: `{"tickets_synced": N, "comments_synced": M, "teams": [...]}`

    3. `async sync_single_ticket(session: AsyncSession, workspace_id: UUID, access_token: str, linear_issue_id: str) -> LinearTicket | None` -- Fetch a single ticket by ID and upsert. Used by webhook handler (Plan 02-03).

    For upserts, use SQLAlchemy's `insert().on_conflict_do_update()` via `from sqlalchemy.dialects.postgresql import insert`.
