    **OAuth service (backend/src/services/linear_oauth.py):**
    Implement the full OAuth2 lifecycle for Linear. Use httpx (already a dependency) for all HTTP calls. Per user decision: raw httpx + GraphQL, no SDK.

    Functions:
    1. `build_auth_url(state: str, settings: Settings) -> str` -- Construct Linear OAuth authorization URL: `https://linear.app/oauth/authorize` with params: client_id, redirect_uri, response_type=code, scope="read,write", state. The state should be a signed value containing workspace_id to prevent CSRF.

    2. `async exchange_code(code: str, session: AsyncSession, workspace_id: UUID, user_id: UUID, settings: Settings) -> dict` -- POST to `https://api.linear.app/oauth/token` with grant_type=authorization_code, code, redirect_uri, client_id, client_secret. On success:
       - Store access_token and refresh_token in Vault via vault service (not plain text in DB)
       - Upsert OAuthToken row with provider="linear" (access_token field stores Vault secret name reference, NOT the actual token)
       - Upsert WorkspaceIntegration with status="connected", connected_at=now()
       - Fetch Linear organization info via GraphQL `{ organization { id name } }` and store external_id
       - Return the organization info

    3. `async refresh_access_token(session: AsyncSession, workspace_id: UUID, user_id: UUID, settings: Settings) -> str` -- Token refresh with race condition prevention per user decision:
       - Acquire `pg_advisory_xact_lock(hashtext('linear_refresh_' || workspace_id::text))` via `SELECT pg_advisory_xact_lock(hashtext($1))` -- this ensures only one refresh per workspace at a time
       - Read current refresh_token from Vault
       - Check if token_expires_at is still in the future (another process may have already refreshed) -- if so, read and return the current access_token from Vault
       - POST to `https://api.linear.app/oauth/token` with grant_type=refresh_token
       - Store new access_token and refresh_token in Vault (overwrite)
       - Update token_expires_at in OAuthToken row
       - On failure: set WorkspaceIntegration.status = "error", raise an exception
       - Return the new access_token

    4. `async get_valid_access_token(session: AsyncSession, workspace_id: UUID, user_id: UUID, settings: Settings) -> str` -- High-level function that reads the token, checks expiry, and either returns the current token or calls refresh_access_token. This is what sync/webhook code will call.

    5. `async disconnect(session: AsyncSession, workspace_id: UUID, user_id: UUID) -> None` -- Per user decision: revokes tokens but keeps existing ticket data. Soft-delete OAuthToken (set deleted_at), delete Vault secrets, set WorkspaceIntegration.status = "disconnected".
