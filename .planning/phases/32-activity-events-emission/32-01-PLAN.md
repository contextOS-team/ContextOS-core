  <action>
For each of the 5 sync services, add `emit_activity()` calls at sync entry and exit points. Import `emit_activity` from `sync_adapter` and `time` for duration tracking.

**Linear (sync_tickets_for_teams):**
- At function start (after any cursor status update): `emit_activity(session, workspace_id, "sync_started", {"integration": "Linear"})`
- After successful sync, before return: `emit_activity(session, workspace_id, "sync_completed", {"integration": "Linear", "items_count": result["tickets_synced"], "duration_ms": duration_ms})`
- In except block: `emit_activity(session, workspace_id, "sync_completed", {"integration": "Linear", "error": True, "error_message": str(e)[:200]})`
- Use `time.monotonic()` for duration_ms calculation

**GitHub (sync_repos):**
- Same pattern. `items_count` from `result["total_prs"]`. Integration name: "GitHub".
- IMPORTANT: GitHub commits per-repo. Emit sync_completed AFTER the last repo, not inside the per-repo loop.

**GitLab (sync_projects):**
- Same pattern. `items_count` from `result["total_mrs"]`. Integration name: "GitLab".
- Same commit-ordering concern as GitHub -- emit after last project.

**Jira (sync_jira_issues):**
- Same pattern. `items_count` from `result["issues_synced"]`. Integration name: "Jira".

**Notion (run_full_sync):**
- CRITICAL: Notion creates its own session via `async with async_session() as session:`. All emit calls must use THAT local session, placed INSIDE the context manager.
- `items_count` from the local `synced_count` variable (if it exists) or count of processed pages. Integration name: "Notion".
- sync_started at entry of the try block, sync_completed before the context manager exits.

For ALL providers:
- `start_time = time.monotonic()` at the very beginning of the sync function
- `duration_ms = int((time.monotonic() - start_time) * 1000)` before emitting sync_completed
- Error events: emit in the except block with `{"error": True, "error_message": str(e)[:200]}`
- Never let emit_activity failure affect the sync flow (the helper itself is fail-silent, but also don't let import errors or parameter issues propagate)
