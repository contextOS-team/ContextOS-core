## Decisions Made
- Notion token exchange uses HTTP Basic Auth (base64 of client_id:client_secret) per Notion API specification
- Notion tokens are long-lived with no fixed expiry; get_valid_access_token reads from Vault without refresh check
- Background sync creates its own session via async_session() for isolation (same pattern as webhook services)
- Page title extracted by iterating properties for type=title field (Notion pages store titles in properties)
- Migration 00006, config fields, Provider.NOTION, and notion_redirect_uri property were already present from prior context phase

External services require manual configuration before Notion OAuth will function:

- `NOTION_REDIRECT_URI` - set to `{BACKEND_URL}/api/notion/callback` in Notion integration settings
