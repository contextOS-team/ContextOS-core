```python
"""Notion OAuth2 lifecycle service.

Handles authorization URL generation, code exchange with refresh token,
token refresh, disconnect, and access token retrieval. All token values
stored encrypted in Supabase Vault.

Notion OAuth differences from other providers:
- Token exchange uses HTTP Basic Auth (base64(client_id:client_secret))
- Response includes workspace_id, workspace_name, and bot_id
- Access tokens are refreshable (unlike Slack bot tokens)
- Authorization URL uses owner=user parameter
"""
```

Key functions to implement:

- `NOTION_AUTHORIZE_URL = "https://api.notion.com/v1/oauth/authorize"`
- `NOTION_TOKEN_URL = "https://api.notion.com/v1/oauth/token"`
- `NOTION_API_BASE = "https://api.notion.com/v1"`
- `NOTION_VERSION = "2025-09-03"` (latest stable -- required for webhook signature support via X-Notion-Signature; CONTEXT.md references this version)

`class NotionOAuthError(Exception): ...`

`build_auth_url(state, settings) -> str`:
  - Build URL with params: client_id, redirect_uri, response_type="code", owner="user", state
  - Use URL encoding for params

`exchange_code(code, session, workspace_id, user_id, settings) -> dict`:
  - POST to NOTION_TOKEN_URL with Basic Auth header (base64 of client_id:client_secret)
  - Body: {"grant_type": "authorization_code", "code": code, "redirect_uri": settings.notion_redirect_uri}
  - Content-Type: application/json
  - Extract: access_token, refresh_token, workspace_id (Notion's), workspace_name, bot_id
  - Store access_token in Vault: token_name(Provider.NOTION, workspace_id, "access")
  - Store refresh_token in Vault: token_name(Provider.NOTION, workspace_id, "refresh")
  - Notion tokens do NOT have a fixed expiry (they're long-lived but refreshable). Set token_expires_at=None.
  - Use upsert_oauth_token and upsert_workspace_integration from oauth_common
  - Store workspace_name in config.external_name and Notion workspace_id in external_id
  - Store bot_id in OAuthToken.metadata_
  - Commit session
  - Return {"workspace_id": notion_ws_id, "workspace_name": ws_name}

`refresh_access_token(session, workspace_id, user_id, settings) -> str`:
  - Read refresh token from Vault
  - POST to NOTION_TOKEN_URL with Basic Auth
  - Body: {"grant_type": "refresh_token", "refresh_token": refresh_token_value}

  - Commit and return new access token value

  - Raise NotionOAuthError if no token found

`disconnect(session, workspace_id, user_id)`:
  - Build vault names: token_name(Provider.NOTION, workspace_id, "access") and "refresh"
  - Call disconnect_provider from oauth_common

`class NotionClient`:
  - `__init__(self, access_token: str)`: Store token, create headers dict with `Authorization: Bearer {token}`, `Notion-Version: NOTION_VERSION`, `Content-Type: application/json`
  - `async def _request(self, method, path, **kwargs) -> dict`: Wrapper with retry on 429 (exponential backoff: 1s, 2s, 4s). Uses `async with httpx.AsyncClient() as client`.
  - `async def search_pages(self, start_cursor: str | None = None, page_size: int = 100) -> dict`: POST to `/search` with filter `{"property": "object", "value": "page"}`. Returns raw response with `results`, `has_more`, `next_cursor`.

  - `async def get_page(self, page_id: str) -> dict`: GET `/pages/{page_id}`
  - `async def get_block_children(self, block_id: str, start_cursor: str | None = None) -> dict`: GET `/blocks/{block_id}/children` with pagination params.
  - `async def get_all_blocks(self, block_id: str) -> list[dict]`: Recursively fetch all blocks for a page. For each block with `has_children=True`, recursively fetch children and attach as `block["children"]` list. Depth limit of 5 levels to prevent runaway recursion.
  - `async def get_page_markdown(self, page_id: str) -> str`: Fetch all blocks for page, convert to markdown via `blocks_to_markdown`.

`def blocks_to_markdown(blocks: list[dict], indent: int = 0) -> str`:
  Convert Notion blocks to clean markdown. Handle these block types:
  - `paragraph` -> plain text with newline
  - `heading_1` -> `# text`
  - `heading_2` -> `## text`
  - `heading_3` -> `### text`
  - `bulleted_list_item` -> `- text` (with indent for nested)
  - `numbered_list_item` -> `1. text` (with indent for nested)
  - `to_do` -> `- [x] text` or `- [ ] text` based on `checked`
  - `toggle` -> `> text` (blockquote style for toggles)
  - `code` -> fenced code block with language
  - `quote` -> `> text`
  - `callout` -> `> emoji text`
  - `divider` -> `---`
  - `image` -> `![caption](url)`
  - `table` -> markdown table (header row + separator + data rows)
  - `child_page` -> `[Page: title](notion_url)` (reference only)
  - `child_database` -> `[Database: title]` (reference only)
  - Other/unknown -> skip with comment `<!-- unsupported: {type} -->`

  For each block, if it has `children` list, recursively convert with indent+1.

`def _rich_text_to_plain(rich_text: list[dict]) -> str`:
  Convert Notion rich text array to plain text string. Handle:
  - `text` type: extract `plain_text`, apply markdown formatting for `bold`, `italic`, `strikethrough`, `code` annotations
  - `mention` type: extract relevant text
  - `equation` type: wrap in `$...$`
