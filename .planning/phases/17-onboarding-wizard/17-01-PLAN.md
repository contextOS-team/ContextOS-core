    If `animate-fade-in-up` (which includes translateY) is close enough to the desired crossfade, use it directly and skip this task. The CONTEXT.md specifies "crossfade, CSS-only, opacity 1->0 / 0->1, ~200ms spring curve, NOT horizontal slide."

    ```css
    .animate-step-enter {
      animation: step-enter 200ms cubic-bezier(0.34, 1.56, 0.64, 1) both;
    }

    @keyframes step-enter {
      from { opacity: 0; }
      to { opacity: 1; }
    }
    ```

    This provides the pure opacity crossfade the design calls for. The wizard wraps each step in a div with `key={step}` and `className="animate-step-enter"` so remounting triggers the fade-in.
