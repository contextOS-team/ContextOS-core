   a. **useContextPagesRealtime** custom hook that subscribes to postgres_changes on the `context_pages` table.
   - Accept `onInsert` and `onUpdate` callbacks (both optional).
   - Inside useEffect: create supabase client via `createClient()`, create channel named `'context-pages-changes'`, subscribe to `postgres_changes` with `event: '*'`, `schema: 'public'`, `table: 'context_pages'`.
   - In the callback, dispatch to onInsert for INSERT events and onUpdate for UPDATE events.
   - CRITICAL: In the cleanup function, call `supabase.removeChannel(channel)` -- this prevents the "TooManyChannels" error with React Strict Mode (documented concern in STATE.md).
