<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to FastAPI action endpoints | Untrusted user requests mutate candidate and suggestion lifecycle state. |
| Candidate to graph Decision Receipt | Unconfirmed detection becomes trusted decision memory only after user confirmation. |
| Candidate to existing artifact evidence | Source quote/rationale can be attached to an existing workspace artifact evidence trail. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-03-01 | Elevation of Privilege | Action endpoints | mitigate | Use `get_current_user`, never trust client workspace IDs, and load candidates/suggestions by `candidate_id` plus `user.workspace_id`. |
| T-45-03-02 | Tampering | Lifecycle transitions | mitigate | Enforce legal transitions and reject repeated/destructive actions on terminal states. |
| T-45-03-03 | Repudiation | Review actions | mitigate | Record actor/user ID, lifecycle reason, timestamp, and related suggestion resolution for confirm/reject/defer/evidence actions. |
| T-45-03-04 | Information Disclosure | Evidence attachment | mitigate | Attach evidence only to matched entities in the same workspace and preserve source links/quotes under workspace-scoped graph writes. |
| T-45-03-05 | Denial of Service | Duplicate/destructive actions | mitigate | Make confirm/add-evidence/idempotent where safe and return conflict/invalid-transition errors for duplicate submissions. |
| T-45-SC | Tampering | Package installs | accept | No package-manager install tasks are planned; use existing FastAPI, SQLModel, graph, and pytest tooling. |
</threat_model>
