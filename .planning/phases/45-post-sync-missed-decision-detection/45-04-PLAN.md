<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FastAPI review API to browser | Workspace-scoped candidate evidence and quotes become visible in React. |
| Browser actions to FastAPI | User clicks mutate candidate/suggestion lifecycle through authenticated requests. |
| Source quote rendering | Untrusted workspace text is displayed in the dashboard. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-04-01 | Information Disclosure | `NeedsReviewSuggestions` data fetch | mitigate | Use authenticated `apiFetch`, trust backend workspace filtering, and render no row whose workspace is absent/mismatched in the typed payload. |
| T-45-04-02 | Tampering | Source quote rendering | mitigate | Render quotes as React text only; do not use `dangerouslySetInnerHTML`, markdown rendering, canvas, or SVG text for source quotes. |
| T-45-04-03 | Elevation of Privilege | UI action helpers | mitigate | Action helpers send only candidate IDs to authenticated backend endpoints; backend validates workspace ownership. |
| T-45-04-04 | Denial of Service | Dashboard layout | mitigate | Bound dashboard display to top 3 by default and hard cap 5; hide empty state so review items cannot displace `Recent decisions`. |
| T-45-04-05 | Repudiation | Destructive UI actions | mitigate | Require explicit alert-dialog confirmation for `Dismiss candidate` and `Ignore duplicate`; backend records actor/reason per Plan 45-03. |
| T-45-SC | Tampering | Package installs | accept | No package-manager install tasks are planned; use existing shadcn/Radix, sonner, Vitest, and apiFetch patterns. |
</threat_model>
