## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| retrieval trace -> context page JSONB | Internal ranking metadata becomes API-visible source metadata. |
| source snippets -> LLM prompt | Untrusted source text is included in prompt context. |
| streaming route -> persisted source explanation | SSE progress must not bypass provenance checks. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-46-04-03 | Information Disclosure | context source metadata | mitigate | Serialize active-workspace sources only; carry references and snippets, not full provider records. |
| T-46-04-04 | Tampering | stale/generated context in synthesis | mitigate | Label freshness and generated context before prompt construction. |

</threat_model>
