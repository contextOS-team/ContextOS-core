<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| suggestion generator -> user-visible queue | Internal scoring becomes a visible Needs review item. |
| candidate action hints -> later action layer | Metadata could be mistaken for authorization to write externally. |
| source text -> suggestion explanation | Untrusted text may contain instructions or misleading action language. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-05-01 | Tampering | suggestion explanation generation | mitigate | Explanation fields come from validators and source metadata, not untrusted source instructions. |
| T-46-05-02 | Elevation of Privilege | action hints | mitigate | Explicit no-write boundary label and tests proving no external write calls. |
| T-46-05-03 | Repudiation | suggestion provenance | mitigate | Preserve candidate ID, generator, match status, quality gate, and source quote/link in payloads. |
| T-46-05-04 | Denial of Service | Needs review noise | mitigate | Suppress weak, duplicate, prompt-injected, or unsupported suggestions with deterministic reasons. |
| T-46-05-05 | Information Disclosure | source evidence in suggestions | mitigate | Store only required quotes/links/source refs for active workspace suggestions. |
| T-46-05-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task exists in this plan. |
</threat_model>
