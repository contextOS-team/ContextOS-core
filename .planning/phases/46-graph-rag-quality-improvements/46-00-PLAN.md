<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| eval fixture -> eval runner | JSONL content is local but still untrusted input to parser/scorer. |
| retrieval trace -> future synthesis/UI | Trace fields will later influence user-visible explanations and must not treat source text as instructions. |
| workspace-scoped source IDs -> metrics | Workspace identity is a safety invariant, not a ranking preference. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-00-01 | Information Disclosure | `GraphRagEvalCase` / `RetrievalTraceItem` | mitigate | Workspace mismatch is a hard eval failure; tests include cross-workspace negative cases. |
| T-46-00-02 | Tampering | JSONL fixture source text | mitigate | Eval runner treats source text as data only and has no instruction execution path, no network, and no model calls. |
| T-46-00-03 | Repudiation | eval JSON output | mitigate | Emit case-level failures with metric names and source IDs so quality claims are auditable. |
| T-46-00-04 | Information Disclosure | source/provenance trace payloads | mitigate | Dataset and contracts require source IDs/links but avoid full raw documents in traces. |
| T-46-00-05 | Tampering | stale/generated context scoring | mitigate | Include stale/supersession and generated-context downranking cases before ranking code changes. |
| T-46-00-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task exists in this plan; Package Legitimacy Audit in RESEARCH says no new packages. |
