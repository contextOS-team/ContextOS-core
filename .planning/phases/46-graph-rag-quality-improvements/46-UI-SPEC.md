# Phase 46 - UI Design Contract

> Visual and interaction contract for Graph RAG provenance, retrieval explanations, freshness, and suggestion grounding surfaces. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | new-york, neutral base, Tailwind v4 CSS variables |
| Component library | Existing shadcn primitives plus custom dashboard utilities; no broad redesign component set |
| Icon library | lucide for secondary navigation/disclosure/status icons only; primary evidence actions must include text labels |
| Font | Geist Sans for dashboard UI, Geist Mono for source IDs, graph paths, retrieval targets, scores, and trace metadata |

Source of truth: `apps/web/components.json`, `apps/web/src/app/globals.css`, `apps/web/src/app/dashboard/context/[id]/page.tsx`, `apps/web/src/app/dashboard/decisions/[id]/page.tsx`, `apps/web/src/app/dashboard/suggestions/page.tsx`, `apps/web/src/app/dashboard/pulse/*`, and the approved Phase 45 UI contract.

## Phase Screen Contract

| Surface | Contract |
|---------|----------|
| Primary screen | Existing context page detail. Phase 46 may enrich the left `Sources` sidebar and source rows with compact retrieval signals once backend metadata exists. |
| Secondary screen | Decision detail. Add verification/freshness/trace metadata only when the API returns source-backed fields; do not make Decision Receipts look provisional. |
| Suggestion surface | `Needs review` / `/dashboard/suggestions` may show why a suggestion was selected or suppressed, but must keep Phase 45 review hierarchy and labels. |
| Graph surface | `/dashboard/graph` may deep-link to a focused graph neighborhood; Phase 46 should not replace the graph canvas or add a new explorer shell. |
| First viewport hierarchy | Context title and generated content remain primary. Source explanation is supporting evidence in the sidebar or inline disclosure, not a new hero panel. |
| Focal point | The active source row or selected Decision source quote is the visual anchor when explanation metadata is opened. |
| Out-of-scope UI | No chat prompt, broad search redesign, autonomous action controls, task/doc/PR creation UI, new dashboard queue, or landing-page treatment. |

## Retrieval Explanation Contract

| Element | Contract |
|---------|----------|
| Source row | Show provider/type label, title, score, and optional signal chips. Keep rows dense enough for 8-12 sources without turning the sidebar into cards. |
| Signal chips | Use neutral chips for `decision receipt`, `source evidence`, `graph path`, `related work`, `reranked`, `fresh`, `stale`, `confirmed`, and `generated context`. Do not color-code every chip. |
| Trace disclosure | Trigger label is `Show source path`. It opens inline details below the source row or a small side disclosure, not a modal unless the content exceeds the sidebar width. |
| Graph path | Render as compact text using Geist Mono for node/edge IDs and arrows, for example `RD-973 -> Slack thread -> Decision`. Keep relationship labels readable text, not raw enum dumps. |
| Ranking features | Show only human-meaningful features: `graph depth 1`, `fresh source`, `confirmed decision`, `primary evidence`, `reranked`. Avoid exposing raw model scores unless in a developer/debug section. |
| Dropped/suppressed explanations | If surfaced, label as `Not used` with a short reason such as `stale duplicate` or `generated context was not primary evidence`. Never imply suppressed evidence supports the answer. |
| Missing metadata | If backend does not return explanation fields, omit the trace area. Do not render placeholder chips such as `unknown signal` in user-facing UI. |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon/text gaps, graph-path arrow gaps, tiny score separators |
| sm | 8px | Source chip gaps, trace row vertical rhythm, compact button padding |
| md | 16px | Source row padding, sidebar group spacing, inline disclosure padding |
| lg | 24px | Detail panel gaps, context section spacing, suggestion row grouping |
| xl | 32px | Main content/sidebar gutter and major stacked sections |
| 2xl | 48px | Page-level breaks only; avoid inside source sidebars |
| 3xl | 64px | Reserved for page-level dashboard layout outside Phase 46 additions |

Exceptions: Fixed-format interactive targets may use 40px minimum height on desktop and 44px on touch breakpoints. These are accessibility exceptions and remain multiples of 4.

## Typography

Declare exactly four size roles and two weights for new Phase 46 UI.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Metadata | 12px | 400 | 1.35 |
| Body | 14px | 400 | 1.5 |
| Row title | 16px | 600 | 1.35 |
| Section heading | 20px | 600 | 1.25 |

Rules:
- Use `text-wrap: pretty` for evidence explanations and source quote body copy.
- Use `font-variant-numeric: tabular-nums` for relevance percentages, graph depth, freshness age, and trace counts.
- Keep `letter-spacing: 0` for all dashboard text. Do not add uppercase tracked labels.
- Use Geist Mono only for identifiers, source IDs, retrieval target names, graph path fragments, and percentages grouped with trace metadata.
- Do not introduce additional font weights. Existing dashboard utilities may remain, but new explanation UI uses only 400 and 600.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` / dark `oklch(0.105 0.012 270)` | Dashboard page background and negative space |
| Secondary (30%) | `var(--card)`, `var(--elevated)`, `.dashboard-panel`, `.pulse-list-panel` | Source sidebar panels, trace disclosures, suggestion rows, Decision detail panels |
| Accent (10%) | `var(--primary)` / dark `oklch(0.70 0.135 168)` | Focus-visible ring, active source path disclosure, selected graph focus, primary trace CTA only |
| Destructive | `var(--destructive)` / dark `oklch(0.65 0.2 25)` | Failed trace load, failed suggestion update, destructive confirmation text if inherited from Phase 45 |

Accent reserved for: focus-visible ring, active navigation inherited from the dashboard, selected graph focus, a single active source-path disclosure marker, and the `Show source path` primary trace action when a source row is selected.

Accent must not be used for every source chip, every link, every hover state, every relevance score, card borders, freshness chips, or decorative glows. Freshness and verification state must be readable from text first.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Show source path |
| Secondary CTA | Open source |
| Empty state heading | No source path available |
| Empty state body | This context page was generated before retrieval explanations were recorded. Regenerate the page to collect source and graph signals. |
| Error state | Could not load source path details. Refresh the context page or regenerate it after source sync completes. |
| Destructive confirmation | None in Phase 46. If a Phase 45 suggestion action is reused, keep its existing confirmation copy unchanged. |

Additional copy rules:
- Use `source path`, `retrieval signal`, `freshness`, `confirmed decision`, `source evidence`, `graph path`, and `generated context` consistently.
- Do not say `AI knows`, `magic`, `autopilot`, `guaranteed`, or `ground truth`.
- Do not say a source proved a decision unless it has exact source evidence or a confirmed Decision Receipt state.
- Use `Not used` for dropped evidence. Do not use `Rejected` unless the user performed a lifecycle action.
- Error copy must always include a path forward: refresh, regenerate, or inspect Activity/source sync status.

## Component Contracts

| Component | Contract |
|-----------|----------|
| `SourceSignalRow` | Existing source row plus optional signal chips. Radius 8px max, neutral hover, no decorative color stripe. Title truncates to one line; metadata wraps below. |
| `SourcePathDisclosure` | Inline disclosure under a source row. Contains why selected, graph path, freshness, verification state, and selected/dropped reason if present. Close/open state must not shift unrelated rows more than the disclosure height. |
| `RetrievalSignalChip` | Neutral chip, 20-24px min-height, text label required. Icons optional and secondary. No icon-only chips. |
| `FreshnessLabel` | Text-first label: `fresh source`, `stale source`, `unknown freshness`, or `confirmed source of record`. No green/yellow/red risk scale. |
| `VerificationLabel` | Text-first label: `confirmed decision`, `source-backed candidate`, `source evidence`, `generated context`, or `unknown verification`. Use neutral treatment except destructive/error states. |
| `GraphPathLine` | Compact path with readable node labels. Use separators and wrapping, not a horizontal scroll trap. Long IDs may be copied from title attributes or details text. |
| `SuggestionExplanationLine` | Optional one-line support under suggestion body: `Selected because {reason}` or `Suppressed because {reason}`. Must be omitted if the reason is not available. |
| `TraceLoadingState` | 2-3 skeleton rows inside the disclosure only. Do not add a full-page loading state for trace metadata. |

## State And Data Contract

| State | UI Contract |
|-------|-------------|
| No explanation fields | Hide signal chips and trace disclosure. Keep the current source list behavior. |
| Explanation loading | Show skeletons inside the open disclosure. The source row remains readable and stable. |
| Explanation available | Show `Show source path`, signal chips, why-selected text, freshness, verification, and graph path when present. |
| Generated context source | Label as `generated context`; never style as a primary source of record. |
| Stale source | Label as `stale source` and include why it was still selected or why it was dropped. |
| Confirmed Decision | Label as `confirmed decision` and preserve source quote/source link before showing action-grounding claims. |
| Dropped evidence | Keep collapsed by default. If shown, use `Not used` plus the suppression reason. |
| Trace load error | Inline error inside the disclosure: `Could not load source path details. Refresh this page.` Keep the source row available. |
| Workspace mismatch | Do not render the row. Workspace scope remains a hard filter, not a visual warning. |

Workspace isolation is a UI requirement: fetches and mutations must use active workspace context, and no source, graph path, suggestion explanation, or trace row should render if its workspace does not match the selected workspace.

## Motion And Interaction Contract

| Interaction | Contract |
|-------------|----------|
| Page load | Preserve existing dashboard/context page load behavior. Do not add section entrance animations for trace metadata. |
| Source row hover | Background-color transition only, 160ms, gated behind `@media (hover: hover) and (pointer: fine)`. |
| Disclosure open | Opacity and translateY up to 4px, 140-180ms. Do not animate height, padding, margin, or layout properties. |
| Button press | `transform: scale(0.96)` for trace/action buttons, 100-120ms, `cubic-bezier(0.23, 1, 0.32, 1)`. Do not scale the whole source list. |
| Graph focus link | Existing navigation transition only. If focusing a graph node, use current graph selection behavior rather than a new page animation. |
| Reduced motion | Remove transform movement. Keep color and opacity transitions only when they aid comprehension. |

Animation rules:
- Never use `transition: all`.
- Use CSS transitions or existing Radix/shadcn behavior for small effects; do not add Motion/Framer Motion for Phase 46.
- Do not add shimmer, glow, pulse, gradient orb, or bokeh decoration.

## Accessibility Contract

| Area | Contract |
|------|----------|
| Hit area | `Show source path`, `Open source`, disclosure triggers, and graph-focus links are at least 40px high on desktop and 44px on touch breakpoints. |
| Labels | No icon-only primary trace actions. Any icon-only secondary trigger must have an accessible name tied to the source title. |
| Focus | Use the global tokenized focus ring. Do not remove outlines. |
| Disclosure semantics | Use a real button with `aria-expanded` and `aria-controls`, or native `details`/`summary` styled to match dashboard utilities. |
| Source quote | Preserve quote text as real text, not canvas/SVG. If visually clamped, full text remains available in the disclosure or accessible text. |
| Color dependence | Freshness, verification, selected, dropped, and error states must be readable from text, not color alone. |
| Keyboard | Enter/Space toggles source-path disclosure. Focus returns to the trigger when the disclosure is closed. |
