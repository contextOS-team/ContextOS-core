<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source text -> LLM-assisted assessment | Slack/docs/tickets are untrusted evidence, not instructions. |
| candidate -> suggestion | Internal extraction output becomes user-visible review state. |
| Phase 45 tables -> Phase 46 evals | Existing schema must be present before quality tests rely on candidate/suggestion payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-01-01 | Tampering | `suggestion_quality.py` | mitigate | Reject prompt-injection-like source text as instructions; source text can only support evidence fields. |
| T-46-01-02 | Repudiation | missed-decision suggestion payloads | mitigate | Preserve candidate ID, generator, source quote/link, match status, and quality gate names in provenance. |
| T-46-01-03 | Information Disclosure | suggestion evidence JSONB | mitigate | Store source references and exact quotes only; do not copy full source records into suggestion payloads. |
| T-46-01-04 | Denial of Service | suggestion quality evals | mitigate | Deterministic fixture runner avoids live model/network calls and stays within validation latency. |
| T-46-01-05 | Elevation of Privilege | action_prompt family | mitigate | Action prompts are assessed and explained only; no external write APIs are called in Phase 46. |
| T-46-01-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install task exists in this plan; Package Legitimacy Audit says no new packages. |
</threat_model>
