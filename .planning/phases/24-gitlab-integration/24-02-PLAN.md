**1. Create `gitlab_common.py`** (mirror `github_common.py` ~178 lines):
- Constants: `GITLAB_API_BASE = "https://gitlab.com/api/v4"`, `GITLAB_AUTH_URL = "https://gitlab.com/oauth/authorize"`, `GITLAB_TOKEN_URL = "https://gitlab.com/oauth/token"`
- `gitlab_headers(token: str) -> dict` -- returns `{"Authorization": f"Bearer {token}", "Accept": "application/json"}`
- `parse_link_next(link_header: str | None) -> str | None` -- parse RFC 5988 Link header for `rel="next"` URL (can reuse GitHub's if extracted, or reimplement -- it's ~10 lines)
- `parse_gitlab_timestamp(ts: str | None) -> datetime | None` -- parse ISO8601 timestamps from GitLab API
- `is_bot_user(user_data: dict) -> bool` -- check `user_data.get("bot", False)` (GitLab uses `bot` field, not name suffix)
- `map_mr_state(gitlab_state: str) -> str` -- map `opened`->`open`, `closed`->`closed`, `merged`->`merged`, `locked`->`closed`
- Custom exception class `GitLabOAuthError(Exception)`
- `async def ensure_valid_token(session, workspace_id, settings) -> str` -- read access token from Vault, check expiry from oauth_tokens table, refresh if within TOKEN_REFRESH_BUFFER using refresh_token + GITLAB_TOKEN_URL. Pattern: read oauth_tokens row, check token_expires_at, if expired call refresh endpoint, update Vault + oauth_tokens. Return valid access_token.

**2. Create `gitlab_oauth.py`** (mirror `github_oauth.py` ~418 lines but simpler -- standard OAuth2 not App JWT):
- `build_auth_url(state: str, settings) -> str` -- construct authorization URL with `client_id`, `redirect_uri`, `response_type=code`, `state`, `scope=read_api`
- `async def _exchange_code(code: str, settings) -> dict` -- POST to GITLAB_TOKEN_URL with `client_id`, `client_secret`, `code`, `grant_type=authorization_code`, `redirect_uri`. Return response JSON.
- `async def handle_callback(code: str, state: str, session, settings) -> dict`:
  1. `verify_state_or_raise(state, settings.GITLAB_CLIENT_SECRET, GitLabOAuthError)` to get workspace_id
  2. Exchange code for tokens
  3. GET `/user` to get current user info (username, name, id)
  4. Store access_token and refresh_token in Vault via `store_token`
  5. `upsert_oauth_token(...)` with provider=Provider.GITLAB, scopes=["read_api"], metadata={"username": ..., "name": ...}
  6. `upsert_workspace_integration(...)` with external_id=str(user_id)
  7. Return {"account": username, "workspace_id": str(workspace_id)}
- `async def disconnect(session, workspace_id, user_id, settings) -> None` -- call `disconnect_provider` from oauth_common, then delete Vault tokens
- `async def get_status(workspace_id, session) -> dict` -- query workspace_integrations for GITLAB, return {"status": ..., "account": ..., "connected_at": ...}

**3. Create `gitlab_repos.py`** (mirror `github_repos.py` ~231 lines):
- `async def refresh_repos(workspace_id, session, settings) -> list[dict]`:
  1. Get valid token via `ensure_valid_token`
  2. GET `/projects?membership=true&per_page=100&order_by=last_activity_at&sort=desc` with pagination
  3. Map each project to `{"id": p["id"], "path_with_namespace": p["path_with_namespace"], "name": p["name"], "visibility": p["visibility"], "web_url": p["web_url"]}`
  4. Cache in workspace_integrations.config under `"available_projects"` key
  5. Return project list
- `async def get_cached_repos(workspace_id, session) -> list[dict]` -- read from config JSONB
- `async def save_selected_repos(workspace_id, project_ids: list[int], session) -> list[int]` -- validate against cached, save to config under `"selected_projects"` key. Use numeric project IDs (not paths -- per research pitfall 2).
- `async def is_project_monitored(workspace_id, project_id: int, session) -> bool` -- check if project_id in selected_projects

**1. Create `gitlab_sync.py`** (mirror `github_sync.py` ~438 lines):
- `async def sync_projects(workspace_id, project_ids: list[int], session, settings) -> None`:
  1. Get valid token via `ensure_valid_token`
  2. For each project_id: fetch MRs via GET `/projects/{project_id}/merge_requests?state=all&order_by=updated_at&sort=desc&per_page=100`
  3. Paginate using `parse_link_next` on Link header
  4. For each MR: upsert into `gitlab_merge_requests` using `workspace_id + gitlab_id` unique constraint
  5. Map fields: `gitlab_id=mr["id"]`, `project_id=mr["project_id"]`, `project_path=mr["references"]["full"].rsplit("!", 1)[0]` or from project data, `iid=mr["iid"]`, `state=map_mr_state(mr["state"])`, `source_branch=mr["source_branch"]`, `target_branch=mr["target_branch"]`, `author=mr["author"]["username"]`, `is_draft=mr.get("draft", False) or mr.get("work_in_progress", False)`, raw_data=mr
  6. After MR upsert: fetch notes via GET `/projects/{project_id}/merge_requests/{iid}/notes?per_page=100` (skip system notes where `system=true`)
  7. Upsert notes into `gitlab_reviews` with `state="note"` for regular notes, `state="approved"` for approval-type
  8. Link MRs to Linear tickets via `link_mr_to_ticket` (see gitlab_linking)
  9. Use backfill window of 60 days on first sync, cursor-based on subsequent (use `updated_after` param)
  10. Update sync status in workspace_integrations.config under `"project_sync_status"`
  11. Enqueue embedding jobs for MR descriptions via `enqueue_embedding_job`

**2. Create `gitlab_webhook.py`** (mirror `github_webhook.py` ~499 lines):
- `async def verify_webhook_token(request_token: str, settings) -> bool` -- constant-time comparison of `X-Gitlab-Token` header against `settings.GITLAB_WEBHOOK_SECRET` using `hmac.compare_digest`
- `async def process_gitlab_event(payload: dict, session, settings) -> None`:
  1. Read `object_kind` from payload
  2. If `object_kind == "merge_request"`: extract MR data from `payload["object_attributes"]`, project from `payload["project"]`. Upsert MR. Link to Linear if new.
  3. If `object_kind == "note"` and `payload["object_attributes"]["noteable_type"] == "MergeRequest"`: extract note data, find parent MR by `iid + project_id`, upsert into gitlab_reviews
  4. Record webhook delivery via `WebhookDelivery` model for idempotency (use `payload.get("object_attributes", {}).get("id")` or generate unique delivery ID)
- Handle MR state transitions: `open`, `close`, `reopen`, `merge`, `update`, `approval`

**3. Create `gitlab_linking.py`** (mirror `github_linking.py` ~155 lines):
- `async def link_mr_to_ticket(workspace_id, source_branch: str, mr_id: uuid.UUID, session) -> uuid.UUID | None`:
  1. Reuse `extract_linear_issue_id(source_branch)` from github_linking -- branch name patterns are provider-agnostic
  2. Reuse `get_linear_team_keys(workspace_id, session)` from github_linking
  3. If ticket ID found, update `gitlab_merge_requests.linear_ticket_id`
  4. Return the linear_ticket_id or None
- Import and delegate to the existing github_linking functions for the actual parsing logic. Do NOT duplicate the regex.

**4. Create `backend/src/routers/gitlab.py`** (mirror `github.py` router ~411 lines):
- `router = APIRouter(prefix="/api/gitlab", tags=["gitlab"])`
- **GET /connect** -- `sign_oauth_state(workspace_id, settings.GITLAB_CLIENT_SECRET)`, `build_auth_url(state, settings)`, return `{"authorization_url": url}` (note: GitHub returns `installation_url`, GitLab returns `authorization_url` to match Linear/Slack pattern)
- **GET /callback** -- accepts `code` and `state` query params (NOT `installation_id` like GitHub). NOT auth-protected (redirect). Calls `handle_callback(code, state, session, settings)`. Redirects to `/dashboard/integrations?gitlab=connected&account={account}` on success, `?gitlab=error&reason=...` on failure.
- **POST /disconnect** -- auth-protected, calls disconnect
- **GET /status** -- auth-protected, calls get_status
- **GET /repos** -- returns cached projects + selected_projects
- **POST /repos/refresh** -- fetches fresh project list from GitLab API
- **POST /repos/select** -- body: `{"project_ids": [int]}`, saves selected projects
- **POST /sync** -- triggers background sync for selected projects (202 Accepted)
- **GET /sync/status** -- returns per-project sync status from config JSONB
- **POST /webhook** -- receives GitLab webhook POST, verifies X-Gitlab-Token header, processes event. NOT auth-protected.

**5. Update `backend/src/main.py`**:
- Add import: `from src.routers.gitlab import router as gitlab_router`
- Register router alongside existing ones (after github_router import/registration)

Do NOT include code indexing endpoints (those are GitHub-specific with tree-sitter). GitLab code indexing can be added later if needed.
