Create migration `00019_gitlab_tables.sql` following the exact pattern from `00004_github_tables.sql`:

Add `'gitlab'` to both.

2. **Create `gitlab_merge_requests` table:**
   - `id uuid primary key default gen_random_uuid()`
   - `workspace_id uuid not null references workspaces(id) on delete cascade`
   - `linear_ticket_id uuid references linear_tickets(id) on delete set null`
   - `gitlab_id bigint not null` (GitLab's internal MR ID)
   - `project_id bigint not null` (GitLab project numeric ID)
   - `project_path text not null` (e.g. "group/project", for display)
   - `iid integer not null` (project-scoped MR number, like GitHub's `number`)
   - `title text not null`
   - `description text`
   - `state text not null check (state in ('open', 'closed', 'merged'))` (map GitLab's `opened`->`open`, `locked`->`closed`)
   - `author text not null`
   - `source_branch text not null` (GitLab equivalent of GitHub's `branch_name`)
   - `target_branch text not null` (GitLab equivalent of GitHub's `base_branch`)
   - `reviewers text[]`
   - `is_draft boolean default false`
   - `gitlab_created_at timestamptz`
   - `gitlab_updated_at timestamptz`
   - `gitlab_merged_at timestamptz`
   - `raw_data jsonb not null default '{}'`
   - `deleted_at timestamptz`
   - `created_at timestamptz not null default now()`
   - `updated_at timestamptz not null default now()`
   - `unique (workspace_id, gitlab_id)`

3. **Create `gitlab_reviews` table:**
   - `id uuid primary key default gen_random_uuid()`
   - `workspace_id uuid not null references workspaces(id) on delete cascade`
   - `merge_request_id uuid not null references gitlab_merge_requests(id) on delete cascade`
   - `gitlab_id bigint not null` (note/discussion ID)
   - `author text not null`
   - `state text not null check (state in ('approved', 'commented', 'note'))` (GitLab has notes, not formal reviews)
   - `body text`
   - `file_path text`
   - `line_range text`
   - `gitlab_submitted_at timestamptz`
   - `raw_data jsonb not null default '{}'`
   - `deleted_at timestamptz`
   - `created_at timestamptz not null default now()`
   - `updated_at timestamptz not null default now()`
   - `unique (workspace_id, gitlab_id)`

4. **Indexes** (mirror GitHub pattern):
   - `gitlab_merge_requests(workspace_id)`
   - `gitlab_merge_requests(workspace_id, project_path)` (equivalent to repo_full_name index)
   - `gitlab_merge_requests(workspace_id, linear_ticket_id)`
   - `gitlab_reviews(workspace_id)`
   - `gitlab_reviews(merge_request_id)`

5. **RLS** -- enable on both tables with `workspace_data` policy using `workspace_members` check (same as GitHub).

6. **Triggers** -- moddatetime `set_updated_at` on both tables.
