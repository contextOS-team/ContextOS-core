**GREEN phase:** Implement `_find_graph_results()` in `backend/src/services/linking.py`. The function signature:

```python
async def _find_graph_results(
    session: AsyncSession,
    workspace_id: UUID,
    ticket: LinearTicket,
) -> dict[tuple[str, UUID], LinkedItem]:
```

Implementation steps:
1. Import `compute_fingerprint` from `src.services.graph_ops` and `GraphNode` from `src.models.graph_node` (at top of file)
2. Import `GRAPH_MAX_DEPTH` from `src.config` (at top of file)
3. Compute fingerprint: `compute_fingerprint("Ticket", ticket.identifier)`
4. Query GraphNode by workspace_id + fingerprint + not deleted. If None, return empty dict (silent fallback)
5. Call traverse_graph() SQL via `text()`:
   ```python
   traverse_stmt = text("""
       SELECT node_id, entity_type, name, properties,
              edge_relationship_type, depth, path
       FROM traverse_graph(
           CAST(:start_node_id AS uuid),
           CAST(:workspace_id AS uuid),
           :max_depth,
           'both',
           NULL,
           NULL
       )
       WHERE depth > 0
   """)
   ```
   Pass max_depth as GRAPH_MAX_DEPTH + 1 (extra hop budget for same_as edges).
6. Process results:
   - Build a dict mapping node_id -> row for path building
   - For each row where depth > 0:
     - If edge_relationship_type == "same_as", adjust effective depth: effective_depth = depth - 1 (same_as doesn't count). If effective_depth becomes 0, skip (that's the start node alias). Also cap total graph results at 20 to prevent same_as expansion explosion.
     - Score: `WEIGHT_GRAPH * (DEPTH_DECAY ** effective_depth)`
     - Build provenance path string: "graph:" + "->".join of entity_type and edge_relationship_type pairs from the path
     - For entity types with source tables (Ticket, SlackThread, PR, CodeChunk, NotionPage, Meeting), use source_type + source_id from the node to build LinkedItem. For graph-only entity types (Person, Decision, Blocker, Feature, Component), use the node's name and properties for title/snippet directly, with source_id = node_id.
   - Use `_bulk_lookup_source_summaries()` for source-backed entities to get title/snippet
   - For Decision nodes specifically, format snippet using the decision highlighting format: "[DECISION] name | By: person | In: source | Affects: tickets | Confidence: X.X"
7. Wrap entire function body in try/except Exception, log warning on failure, return empty dict (fail-silent per CONTEXT.md)
