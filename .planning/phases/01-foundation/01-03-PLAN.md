**1. Create `apps/web/src/lib/supabase/client.ts` -- Browser Supabase client:**

Use `@supabase/ssr` `createBrowserClient`:
```typescript
import { createBrowserClient } from '@supabase/ssr'

export function createClient() {
  return createBrowserClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
  )
}
```

**2. Create `apps/web/src/lib/supabase/server.ts` -- Server Supabase client:**

Use `@supabase/ssr` `createServerClient` with Next.js cookies:
```typescript
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'
```
Follow the official Supabase Next.js SSR pattern. The server client reads/writes auth cookies for session persistence.

**3. Create `apps/web/src/lib/supabase/middleware.ts` -- Auth session refresh:**

`updateSession` function that creates a Supabase server client in middleware context, calls `getUser()` to refresh the session, and returns the updated response with refreshed cookies. This is the standard Supabase SSR middleware pattern.

**4. Create `apps/web/src/middleware.ts` -- Next.js middleware:**

- Call `updateSession` from the Supabase middleware helper
- Redirect logic:
  - If user is NOT authenticated and path is not `/login`, `/signup`, or `/auth/callback` → redirect to `/login`
  - If user IS authenticated and path is `/login` or `/signup` → redirect to `/`
- Matcher: `/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)` to exclude static assets

**5. Create `apps/web/src/app/(auth)/auth/callback/route.ts`:**

Server route handler for auth callbacks (magic link, OAuth):
- Extract `code` from URL search params
- Exchange code for session using `supabase.auth.exchangeCodeForSession(code)`
- Redirect to `/` (dashboard) on success
- Redirect to `/login?error=auth` on failure

**6. Update `apps/web/src/app/layout.tsx`:**

Root layout with basic HTML structure, Tailwind CSS, and Inter font. No auth provider wrapper needed -- Supabase SSR handles sessions via cookies.

**7. Update `apps/web/package.json`:**

Ensure these dependencies are present (add if missing):
- `@supabase/supabase-js` (should already be there)
- `@supabase/ssr` (should already be there)

**8. Create `apps/web/.env.example`:**

```

NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
