**4. Update `apps/web/src/lib/supabase/middleware.ts`:**
Add `/` to the public paths so unauthenticated users can see the landing page:

Change the `isPublicPath` check from:
```typescript
const isPublicPath =
  pathname === '/login' ||
  pathname === '/signup' ||
  pathname.startsWith('/auth/callback')
```

To:
```typescript
const isPublicPath =
  pathname === '/' ||
  pathname === '/login' ||
  pathname === '/signup' ||
  pathname.startsWith('/auth/callback')
```

This ensures:
- `/` serves the landing page (public, no auth needed)
- `/dashboard` requires auth (redirects to /login if unauthenticated)
- `/login`, `/signup` remain public auth pages
- Authenticated users on `/login` or `/signup` still redirect to `/dashboard`
- Authenticated users on `/` can see the landing page (no redirect -- they might want to see the marketing page)
