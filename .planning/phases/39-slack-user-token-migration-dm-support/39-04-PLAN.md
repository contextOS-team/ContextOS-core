Import placement rule: `poll_user_messages` is imported at the TOP of `sync_scheduler.py`, alongside existing imports like `reconcile_notion`. This makes the symbol a module attribute on `src.services.sync_scheduler`, which tests patch via `monkeypatch.setattr(sync_scheduler, "poll_user_messages", ...)` or `patch("src.services.sync_scheduler.poll_user_messages")`. Deferred imports inside the try block are fragile — they bind `slack_messages.poll_user_messages` in local scope on every call, bypassing any patch applied at the `sync_scheduler.poll_user_messages` name.
