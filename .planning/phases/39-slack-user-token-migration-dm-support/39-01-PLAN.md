<objective>
Lay the OAuth dual-token foundation for Phase 39. Capture Slack user tokens during OAuth, store them in Vault alongside the existing bot token, expose a re-auth-needed signal + DM toggle via the `/api/slack/status` and `/api/slack/dms/toggle` endpoints, and remove the 10-character message filter from the existing Events API path so that short messages like "done" / "approved" are ingested going forward.

Purpose: Everything in Phase 39 depends on a user token being available. This plan ships the OAuth changes, the Vault storage convention (`user_access` suffix), the `slack_user_id` config field, the re-auth signal for existing workspaces, and the filter fix that CONTEXT.md says must apply to BOTH the existing channel webhook path and the new DM polling path. Channel ingestion via the bot Events API is left untouched.

Output:
- Modified `slack_oauth.py` with `SLACK_USER_SCOPES` (DM-only scopes per CONTEXT.md) + dual-token `exchange_code` + `get_user_token()` helper
- Modified `slack_events.py` with `_should_filter` retaining bot + system-subtype filters only (no length check)
- Modified `routers/slack.py` `/status` endpoint adding `needs_reauth` + `include_dms`; new `POST /dms/toggle` endpoint
- Updated test suite covering dual-token exchange, needs_reauth flag, DM toggle endpoint, short-message passthrough
</objective>

    2. Add a new endpoint `POST /dms/toggle`:
       ```python
       @router.post("/dms/toggle")
       async def toggle_dms(
           request: Request,
           user: UserContext = Depends(get_current_user),
           session: AsyncSession = Depends(get_session),
       ) -> dict:
           body = await request.json()
           enabled = bool(body.get("enabled", False))

           stmt = select(WorkspaceIntegration).where(
               WorkspaceIntegration.workspace_id == user.workspace_id,
               WorkspaceIntegration.provider == Provider.SLACK,
           )
           result = await session.execute(stmt)
           integration = result.scalar_one_or_none()
           if integration is None or integration.status != "connected":
               raise HTTPException(status_code=400, detail="Slack not connected")

           user_key = token_name(Provider.SLACK, user.workspace_id, "user_access")
           user_token = await read_token(session, user_key)
           if user_token is None:
               raise HTTPException(status_code=409, detail="needs_reauth")

           updated_config = dict(integration.config) if integration.config else {}
           updated_config["include_dms"] = enabled
           # If enabling for the first time, set a marker so the poller knows to do 7d backfill
           if enabled and "dms_first_enabled_at" not in updated_config:
               from datetime import datetime, timezone
               updated_config["dms_first_enabled_at"] = (
                   datetime.now(timezone.utc).replace(tzinfo=None).isoformat()
               )
           integration.config = updated_config
           await session.commit()
           return {"include_dms": enabled}
       ```
