1. Create `backend/src/routers/telegram.py`:
   - Import: APIRouter, BackgroundTasks, Depends, HTTPException, Request, status from fastapi; AsyncSession from sqlalchemy.ext.asyncio; get_session from src.db; UserContext/get_current_user from src.dependencies; connect_telegram_bot/disconnect_telegram_bot/TelegramError from src.services.telegram_bot; get_settings from src.config; hmac from stdlib
   - `router = APIRouter(prefix="/api/telegram", tags=["telegram"])`

   - POST /connect endpoint:
     * Auth: UserContext = Depends(get_current_user), session = Depends(get_session)
     * Parse body: bot_token = body.get("bot_token", "")
     * Validate non-empty, raise 400 if empty
     * Call connect_telegram_bot(session, user.workspace_id, user.user_id, bot_token, get_settings())
     * Catch TelegramError -> 400
     * Return {"status": "connected", "bot_username": result.get("username")}

   - POST /disconnect endpoint:
     * Auth required
     * Call disconnect_telegram_bot(session, user.workspace_id)
     * Return {"status": "disconnected"}

   - POST /webhook/{workspace_id} endpoint:
     * NO auth (Telegram calls this directly)
     * Verify X-Telegram-Bot-Api-Secret-Token header using hmac.compare_digest against settings.TELEGRAM_WEBHOOK_SECRET
     * Raise 403 if invalid
     * Parse payload
     * Dispatch process_telegram_update to background_tasks for fast 200 response
     * Return {"status": "ok"}
     * Background task function `_process_update_background(payload, workspace_id)`:
       - Create own session via `from src.db import async_session`
       - Call process_telegram_update(session, workspace_id, payload)
       - Catch and log exceptions, rollback on error (same pattern as Fathom _poll_background)

2. Update `backend/src/main.py`:

   - Add `app.include_router(telegram_router)` after the notion_router line
