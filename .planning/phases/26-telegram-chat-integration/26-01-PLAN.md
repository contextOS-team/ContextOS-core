   - Define `TELEGRAM_API_BASE = "https://api.telegram.org/bot{token}"`
   - Define `class TelegramError(Exception): pass`
   - `async def telegram_api_call(bot_token: str, method: str, **params) -> dict`: POST to `{base}/{method}` with json=params using httpx.AsyncClient, raise TelegramError if not data["ok"]
   - `async def connect_telegram_bot(session, workspace_id, user_id, bot_token, settings) -> dict`:
     * Call getMe to validate token, raise TelegramError if invalid
     * Store token in Vault via `store_token(session, token_name(Provider.TELEGRAM, workspace_id, "bot_token"), bot_token)`
     * Call setWebhook with url=`{settings.BACKEND_URL}/api/telegram/webhook/{workspace_id}`, secret_token=settings.TELEGRAM_WEBHOOK_SECRET, allowed_updates=["message", "edited_message"]
     * Upsert oauth_token record (access_token_name=vault_name)
     * Upsert workspace_integration (provider=TELEGRAM, external_id=str(bot_info["id"]), config={"bot_username": bot_info.get("username"), "external_name": f"@{bot_info.get('username', '')}"})
     * Commit and return bot_info
   - `async def disconnect_telegram_bot(session, workspace_id) -> None`:
     * Read bot token from Vault
     * If token exists, call deleteWebhook to unregister
     * Delete token from Vault
     * Update workspace_integration status to "disconnected"
     * Commit
