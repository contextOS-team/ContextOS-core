1. Add a `_get_clone_credentials()` helper function that takes `(provider: str, workspace_id: UUID, session: AsyncSession, settings: Settings)` and returns `(clone_url_prefix: str, token: str)`:
   - If provider == "gitlab": call `ensure_valid_token(session, workspace_id, settings)` from `gitlab_common`, return `(f"https://oauth2:{token}@gitlab.com/", token)`
   - Else (github): call `get_installation_token(workspace_id, session, settings)` from `github_oauth`, return `(f"https://x-access-token:{token}@github.com/", token)`. Catch `GitHubOAuthError` and return None.

2. Add `provider: str = "github"` parameter to `index_repo()`. Replace the hardcoded GitHub token retrieval with `_get_clone_credentials(provider, ...)`. Build clone_url as `f"{clone_url_prefix}{repo_full_name}.git"`. On failure (None return), return `_empty_result`.

3. Add `provider: str = "github"` parameter to `_update_index_status()`. Change the hardcoded `provider == "github"` filter to use the parameter value.

4. Create `index_gitlab_workspace_repos()` function mirroring `index_workspace_repos()` but using GitLab imports:
   - Import `get_cached_repos` from `gitlab_repos` and `is_project_monitored` from `gitlab_repos`
   - Call `_update_index_status(workspace_id, session, "indexing", provider="gitlab")` at start

   - Call `_update_index_status(workspace_id, session, "idle", last_at=..., provider="gitlab")` at end
