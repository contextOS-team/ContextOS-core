- Marketing-copy descriptions fully removed (not replaced with placeholders) -- the integration name + external_name + connected_at provide sufficient context
- draw-ring animation removed alongside pulse-dot since the setup progress ring SVG was eliminated in the home page redesign
- Connection info (external name, timestamp) moved inline with card header row rather than separate section
