**Rewrite `apps/web/src/app/dashboard/page.tsx`:**

The current page has: greeting (hero), setup progress ring, 4 integration cards in a grid. The problems: greeting dominates, cards are sparse, lots of empty space, marketing-copy feel.

New design (Claude's discretion on exact layout, but following CONTEXT decisions):

**Header area (compact):**
- Greeting becomes a single subtle line: `text-sm text-muted-foreground` -- e.g., "Good afternoon, Daulet" -- NOT the h2 hero it is now
- The `connected X/4` counter moves into the header line or becomes part of a status bar
- Remove the separate "Your workspace at a glance" subtitle (redundant)

**Integration status (the hero section):**
Replace the current 4-column card grid with a denser, more scannable format. Recommended: **Compact status rows** (Linear-inspired):
- Single-column list of integrations, each row ~48px tall
- Each row: brand SVG logo (from brand-logos.tsx) | integration name | external_name or "Not connected" | connected_at timestamp | connect/manage action
- Connected rows have a subtle left border accent in the integration's brand color
- Disconnected rows are visually muted
- Rows inside a card/container for visual grouping

**Status indicators (replacing green pill/pulsing dot):**
- Connected: a small solid circle (4px) in the brand's own color -- no animation, no pulse. The solid dot + "Connected" text (or just the dot) is enough
- Disconnected: a hollow ring (4px, stroke only) in muted color
- Error: a solid circle in destructive red
- No animated pulsing dots anywhere

**Setup progress section:**
- Integrate the "connect" calls directly into the status rows (each disconnected row has an inline connect link)
- The setup ring SVG can be removed entirely if connect actions are inline in the rows

**Quick connect:**
- Each disconnected integration row has a "Connect" text link (not a button) -- clicking triggers the same OAuth flow
- Connected integrations show a "Manage" text link that navigates to /dashboard/integrations
- Fathom (API key) shows "Configure" which navigates to /dashboard/integrations

**Import brand logos:**
```tsx
import { LinearLogo, SlackLogo, GitHubLogo, FathomLogo } from '@/components/icons/brand-logos'
```

Replace all Lucide icon usage (Workflow, MessageSquare, Video, GitBranch) with brand logos.

**Remove unused imports:** Remove Activity, Circle, CheckCircle2, X, and other Lucide icons that are no longer used.

**Keep all existing data fetching logic** (loadData, handleQuickConnect, etc.) -- only change the rendering.
