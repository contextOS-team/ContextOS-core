  <action>
Create three service files mirroring the Linear integration pattern (linear_oauth.py, linear_sync.py, linear_webhook.py).

**jira_oauth.py** (~350 lines, mirror linear_oauth.py):
- Constants: JIRA_AUTHORIZE_URL = "https://auth.atlassian.com/authorize", JIRA_TOKEN_URL = "https://auth.atlassian.com/oauth/token", JIRA_ACCESSIBLE_RESOURCES_URL = "https://api.atlassian.com/oauth/token/accessible-resources"
- JiraOAuthError(Exception) class
- `build_auth_url(state, settings)`: Build auth URL with audience="api.atlassian.com", scopes "read:jira-work write:jira-work read:jira-user manage:jira-webhook offline_access", response_type="code", prompt="consent"
- `exchange_code(code, session, workspace_id, user_id, settings)`:
  1. POST to JIRA_TOKEN_URL with JSON body (NOT form data -- critical Jira difference)
  2. After getting tokens, GET JIRA_ACCESSIBLE_RESOURCES_URL to get cloudId
  3. Use first accessible resource's "id" as cloud_id
  4. Store tokens via vault.store_token
  5. Call oauth_common.upsert_oauth_token and upsert_workspace_integration with config={"cloud_id": cloud_id}
- `refresh_access_token(session, workspace_id, settings)`: Refresh using rotating tokens (store NEW refresh token on each refresh). Use advisory lock pattern from linear_oauth.py to prevent concurrent refreshes.
- `_get_valid_token(session, workspace_id, settings)`: Check expiry, refresh if needed, return valid access token + cloud_id
- `disconnect(session, workspace_id)`: Use oauth_common.disconnect_provider

**jira_sync.py** (~400 lines, mirror linear_sync.py):
- Helper: `_api_url(cloud_id, path)` -> f"https://api.atlassian.com/ex/jira/{cloud_id}/rest/api/3/{path}"
- `sync_jira_issues(session, workspace_id, settings, jql=None)`:
  1. Get valid token + cloud_id via _get_valid_token
  2. Default JQL: "ORDER BY updated DESC" (all issues) or user-provided JQL
  3. Use `/search/jql` POST endpoint with nextPageToken pagination (NOT startAt)
  4. Fields to request: summary, description, status, priority, assignee, reporter, project, labels, comment, created, updated, issuetype
  5. For each issue: upsert JiraIssue (match on workspace_id + jira_id)
  6. For each issue's comments: upsert JiraComment
  7. Use SyncRunLogger for progress tracking
  8. Return sync stats (issues_synced, comments_synced)
- `search_jira_issues(session, workspace_id, settings, query)`: Quick search for UI autocomplete

**jira_webhook.py** (~400 lines, mirror linear_webhook.py):
- `verify_webhook_signature(raw_body, signature_header, secret)`: HMAC-SHA256, X-Hub-Signature header with "sha256=" prefix (same as GitHub pattern)
- `process_jira_webhook(session, payload, workspace_id)`:
  - Handle events: jira:issue_created, jira:issue_updated, jira:issue_deleted, comment_created, comment_updated, comment_deleted
  - For issue events: upsert/soft-delete JiraIssue
  - For comment events: upsert/delete JiraComment
  - Emit activity_event on issue changes
- `register_webhooks(client, cloud_id, access_token, callback_url, jql_filter)`: POST to /webhook endpoint to register
- `refresh_webhooks(client, cloud_id, access_token, webhook_ids)`: PUT to /webhook/refresh to extend expiry

All services must use httpx.AsyncClient for HTTP calls. Use `async with httpx.AsyncClient() as client:` pattern.
