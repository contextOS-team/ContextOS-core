**Webhook Endpoint (backend/src/routers/webhooks.py):**
Add a POST /api/webhooks/github endpoint to the existing webhooks router (which already has /api/webhooks/linear). Follow the EXACT pattern from the Linear webhook handler in the same file:

1. Read raw request body bytes
2. Get `X-Hub-Signature-256` header (GitHub's HMAC signature)
3. Compute HMAC-SHA256 of raw body using GITHUB_WEBHOOK_SECRET
4. Compare with `sha256=...` value from header using hmac.compare_digest (timing-safe)
5. If mismatch, return 401
6. Check `X-GitHub-Delivery` header for idempotency:
   - Query webhook_deliveries for delivery_id with provider="github"
   - If already exists, return 200 (duplicate, skip processing)
   - If new, insert delivery record
7. Parse JSON body, extract `X-GitHub-Event` header (event type)
8. Delegate to background task: process_github_event(event_type, payload, workspace_id)
9. Return 200 immediately (fast response per established pattern)

Use `import src.config as config_module` pattern for settings access (same pattern as existing webhooks.py for test patching reliability).

**Note:** GitHub webhooks are sent to the App-level webhook URL, not per-repo. The payload contains `installation.id` which we use to look up the workspace. Query OAuthToken where provider="github" and metadata_ contains the installation_id to find the workspace_id.

**Webhook Service (backend/src/services/github_webhook.py):**
Follow the pattern from linear_webhook.py:

- `process_github_event(event_type, payload, session)`:
  1. Look up workspace from installation.id in payload -> query OAuthToken metadata
  2. Dispatch by event type:
     - `pull_request` -> handle_pull_request_event(action, payload, workspace_id, session)
     - `pull_request_review` -> handle_review_event(action, payload, workspace_id, session)
     - `pull_request_review_comment` -> handle_review_comment_event(action, payload, workspace_id, session)
  3. Unrecognized events: log and skip

- `handle_pull_request_event(action, payload, workspace_id, session)`:
  Actions: opened, closed, reopened, edited, converted_to_draft, ready_for_review
  1. Check if repo is monitored via is_repo_monitored (if not, skip)
  2. **Filter bot authors**: skip if PR author login matches known bots (dependabot[bot], renovate[bot], github-actions[bot])
  3. Extract PR data from payload.pull_request
  4. Upsert GithubPullRequest (on conflict: workspace_id + github_id)
  5. Set state: map GitHub action to state (closed + merged=true -> "merged", closed -> "closed", opened/reopened -> "open")
  6. Call link_pr_to_ticket from github_linking service
  7. Queue embedding generation stub for PR content changes

- `handle_review_event(action, payload, workspace_id, session)`:
  Action: submitted
  1. Check if repo is monitored
  2. Extract review data: id, user.login, state, body
  3. Look up parent GithubPullRequest by github_id from payload.pull_request.id
  4. Upsert GithubReview (on conflict: workspace_id + github_id)
  5. Set state from review.state (approved, changes_requested, commented, dismissed)

- `handle_review_comment_event(action, payload, workspace_id, session)`:
  Action: created
  1. Check if repo is monitored
  2. Extract: comment body, path (file_path), line/original_line (line_range), user.login (author)
  3. Look up parent PR
  4. Upsert GithubReview record with file_path and line_range filled in
  5. This stores review comments as GithubReview records with file/line context (per user decision: "file path + line range + comment body")

Create own async session for background processing isolation (same pattern as linear_webhook.py and slack_events.py).

**Frontend: API client additions (apps/web/src/lib/api.ts):**
Add GitHub-specific API functions following the existing patterns:

```typescript
// GitHub
export function connectGithub(): Promise<{ installation_url: string }> {
  return apiFetch<{ installation_url: string }>('/api/github/connect')
}

export function disconnectGithub(): Promise<{ status: string }> {
  return apiFetch<{ status: string }>('/api/github/disconnect', { method: 'POST' })
}

export interface GithubRepo {
  full_name: string
  name: string
  private: boolean
  description: string | null
  language: string | null
}

export function getGithubRepos(): Promise<{ repos: GithubRepo[] }> {
  return apiFetch<{ repos: GithubRepo[] }>('/api/github/repos')
}

export function refreshGithubRepos(): Promise<{ repos: GithubRepo[] }> {
  return apiFetch<{ repos: GithubRepo[] }>('/api/github/repos/refresh', { method: 'POST' })
}

export function saveGithubRepoSelection(repoFullNames: string[]): Promise<{ status: string; selected_repos: string[] }> {
  return apiFetch<{ status: string; selected_repos: string[] }>('/api/github/repos/select', {
    method: 'POST',
    body: JSON.stringify({ repo_full_names: repoFullNames }),
  })
}
```
