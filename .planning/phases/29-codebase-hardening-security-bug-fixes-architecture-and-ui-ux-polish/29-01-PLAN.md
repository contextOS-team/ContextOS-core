In `backend/src/services/oauth_common.py`, change the HMAC signing to use `settings.OAUTH_STATE_SECRET` instead of the provider's client secret. Add fallback: if `OAUTH_STATE_SECRET` is empty, fall back to the old behavior (provider client_secret) for backward compatibility during migration.

    4. **Dynamic Redis consumer names (REL-01):** In both `backend/src/services/embedding_worker.py` (line 30) and `backend/src/services/code_index_worker.py` (line 34), replace `CONSUMER_NAME = "worker-1"` with `CONSUMER_NAME = f"worker-{socket.gethostname()}-{os.getpid()}"`.
