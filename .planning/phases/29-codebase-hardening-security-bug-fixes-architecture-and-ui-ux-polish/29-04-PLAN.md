       ```python
       async def _lookup_ticket(session, workspace_id, ticket_identifier) -> tuple[LinearTicket | TicketProxy, str | None]:
       ```
       Extracts the Linear-first, Jira-fallback ticket lookup logic. Returns (ticket, ticket_id_for_fk) where ticket_id_for_fk is the FK value (linear_ticket_id or jira_issue_id). Raises ValueError if ticket not found in any provider.

       ```python
       async def _upsert_context_page_placeholder(session, workspace_id, ticket, ticket_id_for_fk) -> ContextPage:
       ```
       Creates or updates a ContextPage with status="generating". Handles the upsert logic. Calls `session.flush()` and `session.commit()` to persist immediately.

       ```python
       def _build_synthesis_prompt(ticket, related_items: list[LinkedItem]) -> str:
       ```
       Formats the SYNTHESIS_TEMPLATE with ticket info and related content. Pure function (no async, no DB).

    2. **Refactor both paths to use helpers:**
       - `generate_context_page`: Replace inline ticket lookup, placeholder upsert, and prompt building with helper calls. Keep the LLM call and status update inline.
       - `generate_context_page_stream`: Replace inline ticket lookup, placeholder upsert, and prompt building with helper calls. Keep `yield` statements in the generator (do NOT move yields into helpers). The SSE events (`step_start`, `step_complete`) remain in the generator around the helper calls.

    3. **Fix error status propagation (BUG-01):** In BOTH paths, add error status writing in the exception handler:
       ```python
       except Exception as e:
           logger.exception("Generation failed for %s", ticket_identifier)
           try:
               if context_page:
                   context_page.status = "error"
                   await session.flush()
                   await session.commit()
           except Exception:
               logger.warning("Failed to persist error status for %s", ticket_identifier)
           # Stream path: yield error event
           # Non-stream path: raise
       ```

    4. **Fix double flush (BUG-03):** In the non-stream path, ensure the final status update to "ready" does both `flush()` AND `commit()` — not just `flush()`. The caller should not need to commit separately. Check that no redundant flush/commit exists.

       ```python
       MAX_PROMPT_CHARS = 100_000  # ~25k tokens
       ```
       When formatting related content, track character count. If adding the next item would exceed the budget, append `"[Truncated: {N} more items omitted]"` and stop. See research code example.

    6. **Remove dead method (ARCH-05):** Delete `LLMClient.generate_context_page` method from `backend/src/services/llm_client.py` (lines ~120-168). It builds its own prompt independently and is never called.
